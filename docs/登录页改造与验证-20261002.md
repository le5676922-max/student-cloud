# 登录页改造与验证

日期：2026-10-02。

## 本次范围

只改造学生云盘登录界面，不修改后台、数据库、其他业务页面或小芽。

交互基础来自 [CareerCompass](https://github.com/arsh342/careercompass)，视觉进一步参考用户提供的本地视频。保留其 MIT 许可，完整声明位于 `frontend/public/licenses/careercompass.txt`，构建产物也会包含该文件。

采用深色背景、浅灰圆角卡片、下划线表单、黑色登录按钮和四个几何角色。角色支持指针跟随、眨眼、输入联动、密码显隐表情，以及暂停动画。没有加入音乐、视频转场、开场放大、夸张指针或抖音水印。

动画使用现有 Vue 和 CSS，不引入 React、Firebase、Google 认证或额外动画依赖。单个指针监听器按需合并更新；暂停、手机断点、后台页面、不可见区域和减少动态效果设置下停止动画，离开页面时清理监听器、动画帧与计时器。

## 登录接口与入口

继续使用现有账号接口，不能提前将账号改为只接受邮箱的字段。

| 功能 | 现有接口或行为 |
| --- | --- |
| 账号登录 | `POST /user/login` |
| 安全入口登录 | `POST /user/login/{entry}`，保留 `/login/:entry` 路由 |
| 入口校验 | `GET /user/login/entry/validate` |
| 验证方式 | `GET /user/login/verify-mode` |
| 图片验证码 | `GET /user/login/captcha` |
| 登录状态 | `GET /user/login/check` |
| 提交字段 | `username`、`password`、`verifyCode`、`verifyCodeUUID` |
| 成功后跳转 | 沿用全局管理员、工作空间管理员、普通用户的原有跳转 |
| 记住账号 | 仅保存账号偏好，不保存密码 |
| 注册账号 | 保留入口，说明邮箱注册尚未开放、当前联系管理员创建账号 |
| 忘记密码 | 保留入口，说明当前联系管理员重置密码 |

邮箱登录、邮箱自助注册、邮件验证码和邮件找回密码属于下一步，不在本次伪造请求或跳转到不存在的页面。原参考项目的第三方认证和后台没有迁移。

## 验证结果

- 前端 53 项单元测试通过，包括角色权限、账号记忆、角色动画计算等现有测试。
- ESLint 和 Vue 类型检查通过。
- 生产构建通过；现有文件预览等大包警告仍存在，本次没有扩大到全站打包优化。
- 隔离 MySQL 测试环境实测：空字段拦截、错误密码提示、密码显隐、回车登录、管理员跳转、退出、重新进入时保留账号且密码为空。开发页面和生产构建均完成了真实登录；生产页面没有控制台运行错误。
- 实测注册/忘记密码说明弹窗、输入联动、角色高度变化、暂停/播放按钮。
- 桌面 1280 × 720 页面无横向溢出。
- 使用 375 × 667、320 × 480 的同源 iframe 检查实际 CSS 断点。手机隐藏角色，短屏可以滚动，键盘可到达注册入口，没有横向溢出。此项是窄屏布局验证，不代表真实手机浏览器兼容性验收。
- 修复了初次读取验证码模式触发空密码错误提示，以及短屏垂直居中使卡片顶部被裁掉的问题；卡片随内容增高，避免额外验证码/错误提示被固定高度截断。

本次没有强制切换真实账号的验证码或双因素设置，也没有修改业务数据库账号。相关界面和接口保留，但不宣称完成了验证码、双因素、邮箱注册或全站所有业务的端到端测试。

本地查看登录页：`http://127.0.0.1:5173/login`。未提交或推送 Git。
