# 前端交互与业务可靠性优化记录

日期：2026-10-27。范围：本地 Student Cloud 独立后端及现有 Vue 前端。

## 本轮目标

沿用用户选定的深灰外框、浅灰背景、白色面板及少量紫色强调，保留几何角色登录页和小芽。主要完善存储管理、连接编辑、全局总览与交互可靠性，不重新设计品牌，也不切换线上环境。

## 存储管理

- 卡片使用固定 44px 图标，压缩装饰留白，突出名称、类型、空间和实际操作。
- 状态标签只显示状态；启停使用明确按钮，并显示请求进行状态及失败反馈。禁用的存储源不能打开，同时说明原因。
- 除拖动排序外，增加“前移 / 后移”，可用键盘完成排序。排序保存期间阻止其他修改。
- 搜索和状态筛选保存到路由 `q` / `status`；编辑后返回恢复原条件。仅接受白名单状态、最多 120 字的搜索值；连接密钥、参数和完整配置不进入 URL。
- 中文输入法组合期间不提前提交搜索；清空后焦点回到搜索框。
- 同一行重复确认不能重复发起写请求。账号、凭据或路由改变后，旧响应不得回填当前列表。
- 处理交叉请求：A 启用后，B 删除触发的旧列表读取即使更晚返回，也不能恢复 A 的旧状态。通过修改版本检查丢弃过期快照，仅重新读取元数据，不重放写操作。

## 存储连接编辑

- 基本信息、连接参数与保存反馈分组，使用已有主题变量，缩短无操作价值的说明。
- 初始化配置与参数加载完成后才建立草稿基线，避免打开页面立即提示未保存。
- 草稿只在当前组件内存中比较；离开有修改的页面需要确认，取消后保留输入。服务器确认保存成功后才清除未保存状态。
- 页面返回、取消按钮和成功后的导航保留列表筛选；不保存密码或密钥草稿到浏览器持久存储。
- 校验失败定位并聚焦首个问题字段；中文输入法确认文字时不会误识别连接地址或提交表单。

## 全局总览

- 补齐直接进入后台时的站点配置初始化：App 统一确认配置后才加载受保护页面和小芽，后台、文件页、工作空间及自动化页共用已确认结果；登录、安装、SSO 仍可直接打开。失败只在用户明确重试时重新读取，普通导航不重复请求；会话、凭据及后端来源切换时取消旧响应。严格检查 installed 和 accountModel，保留旧后端兼容和自定义后缀默认恢复。真实浏览器冷启动已验证存储源 1、分享记录 0、空间管理员 3 加普通成员 6 等于 9。
- 独立模式不再请求未实现的历史 `/admin/business-metrics` 接口。
- 总览统一读取内容服务已有的全局文件统计，顶部存储 / 分享卡和内容统计面板共用一个请求。
- 普通成员与空间管理员按实际字段分别计数。例如 3 个空间管理员加 6 个成员应显示 9 人，不能从已不包含管理员的成员数再次扣减。
- 分享显示记录总数与有效数，不把“总数减有效数”冒充已过期数量；没有对应管理页面的汇总卡不伪装成可点击入口。
- 未提供、失败、部分可用分别呈现，不用 0 代替未知值；保留账号和凭据隔离以及 GLOBAL / WORKSPACE 范围检查。

## 交互与可访问性

- 表单错误由现有业务校验统一呈现，使用 `novalidate` 避免浏览器原生提示和应用提示相互冲突。课程容量保留原生 number 默认整数约束，空值、0、超范围和小数不能提交。
- textarea 保留既有行数、最小高度及自动增长逻辑，关闭会破坏面板布局的手动尺寸拖动。
- 导航菜单与站点信息弹层触发器复用现有 Element Plus 按钮。
- 小芽窗口可用方向键调整尺寸，Shift 提供更大步长；显示尺寸反馈并支持恢复默认。拖动结束不会误触发恢复。
- 滚动条提供标准 CSS 及 WebKit 样式，高对比度使用系统样式，保留已有减少动画设置。

## 远程读取可靠性

- 慢速远程目录读取结束后再次检查授权版本，撤权期间不能继续返回旧的上传授权或目录能力。
- 核对存储适配器读取结果的对象 key 与请求目标一致；异常时关闭流和客户端并释放资源预算。
- 流的 `skip` 通过受控读取完成，纳入长度计数；禁用不支持的 mark/reset，避免正常跳过后误报长度错误或绕过长度约束。

## 实际浏览器检查

恢复浏览器访问和本地服务后，已使用实际页面完成以下检查；没有保存测试草稿或增删现有存储连接。

1. 搜索“本地”并选择“已启用”，URL 仅写入 q/status；进入编辑再返回后恢复筛选。
2. 修改现有连接名称后离开，显示未保存确认；继续编辑保留草稿，放弃后返回列表且原名称不变。
3. 无匹配搜索显示清空入口；清空后恢复列表并将焦点返回搜索框。
4. 新建表单空名称保存被拦截，焦点转到名称输入；放弃草稿后列表仍为原有 1 个连接。
5. Enter 打开更多菜单、Escape 关闭；只有一个存储源时前移 / 后移不可用。
6. 390px 窄屏下存储管理与总览没有整页横向溢出；总览日期弹层位于视口内，7 / 30 天切换能更新记录范围。
7. 小芽窗口方向键和 Shift 调整尺寸，Enter 恢复默认，操作后关闭面板。
8. 直接重新加载后台总览显示真实独立服务指标，不再出现“接口不存在”，成员构成图显示 3 + 6 = 9。
9. 直接打开自动化任务页面，配置确认后页面与小芽入口正常显示，任务读取结束并呈现实际空状态。
