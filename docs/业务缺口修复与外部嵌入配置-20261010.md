# 业务缺口修复与外部嵌入配置

本文记录 2026-10-10 的实现及边界；实测结果另见同日回归报告。没有向真实云盘写入测试文件。

2026-10-12 的最终全量测试、真实 MySQL 和发布打包结果见 [业务修复与验收报告](业务修复与验收报告-20261012.md)。

## 文件整理与资料索引

普通文件界面和 Agent 的移动、重命名会同步**操作账号本人**的私人索引路径，文件夹按目录段边界匹配，不误更新同名前缀目录。操作前检查关联冲突，成功后复核目标权限及完整 SHA-256，再条件更新。同步失败明确提示文件可能已改变；Agent 标记中断，不自动重试已完成的写入。

其他账号关联的文件及服务器外部移动，不会为了同步而遍历其他人的私人索引。资料库提供“修复路径”，重新验证和索引新路径，不移动、删除原文件。内容或权限变化仍使旧索引失效。

## 缓存与共享限流

全局总览统计默认缓存 10 秒，可配置 1–30 秒。Redis 只接收约束后的统计数据；账号、空间名称、近期登录详情只保存在当前进程的短期缓存。即时权限、登录角色和实例运行状态不由缓存授权。缓存期间新增记录可能尚未显示，不代表实际权限延迟生效。

```dotenv
STUDENT_CLOUD_CACHE_TYPE=redis
STUDENT_CLOUD_OVERVIEW_CACHE_TTL=10s
STUDENT_CLOUD_RATE_LIMIT_TYPE=auto
STUDENT_CLOUD_RATE_LIMIT_FAILURE_MODE=closed
```

Redis Lua 原子计数共享接口和邮件限流。默认 Redis 故障拒绝受保护请求；可选 `local` 降级只能维持单进程计数。生产 Redis 使用 `noeviction`，不能驱逐仍生效的安全计数器。仅信任配置代理，并由 Nginx 覆盖转发头，不能靠伪造 X-Forwarded-For 获得新额度。

Redis **不代表 Sa-Token 登录会话和 Agent 队列已经支持多实例**。生产方案保持一个后端，不能直接横向扩容。

## 邮箱找回密码

登录页“忘记密码”已接真实验证码重置流程。注册和重置用途隔离，单次消费，有有效期、尝试次数、发送冷却及共享额度。公开响应不区分邮箱是否对应有效账号。重置后旧密码、旧会话失效；登录与重置并发会校验凭据版本。

SMTP 在数据库事务外执行，短事务预留窗口、发信成功后条件激活验证码。失败不产生可用验证码、不释放冷却供刷邮件。QQ 邮箱沿用 SMTP 配置，授权码不能进入源码、前端、镜像、报告或日志。

## S3 大目录

S3 家族新增“快速浏览（存储源顺序）”：一次只取当前页，不必枚举全目录才显示第一页。总数未知，分页不累加 DOM；本页全部隐藏时仍可下一页，不误称整个目录为空。

主动排序或全目录名称筛选会切回完整目录模式，首屏可能较慢。短随机游标不暴露云端 token，绑定账号、根路径、驱动、页大小与目录变更代数，默认 5 分钟过期。换账号、撤权或目录变动后需刷新。只签当前授权页的下载地址，不能把页内排序冒充全局排序。

## 可选本地 OCR

默认关闭，纯扫描 PDF 没有文字层时可使用 Tesseract。Docker 镜像安装简体中文和英文包。默认最多 10 页、120 dpi、60,000 字符、单页 15 秒/总 90 秒，像素、文件大小和并发也受限。混合 PDF 不自动补 OCR 图片文字；手写、图表、识别错误需人工校对。

临时图片不写到 Redis 或云盘，没有用户指定命令的入口。模拟引擎测试验证限额、超时和清理，不代表真实扫描件准确率。

## 本地大文件断点续传

本地存储的代理上传在文件达到 8 MiB 时使用续传，分片为 4 MiB，单文件上限 2 GiB。每片校验 SHA-256；用户重新选择同一文件，可以跳过已经确认的分片，不需要从头上传。公网须使用 HTTPS 才能运行浏览器摘要校验。

上传会话绑定账号、存储源、根目录、目标路径与文件摘要，每次操作重新核对权限、目录密码和真实根目录。暂存文件位于独立私有目录，不能作为 LOCAL 存储源或工作空间云盘公开；新建、修改、复制和旧存储源初始化均检查隔离。旧不安全配置会拒绝初始化，应修改目录配置，不会自动移动或删除文件。

取消或刷新不会删除目标文件；续传有效期为 24 小时。每账号最多 8 个活动会话，实例最多 1,000 个会话记录，暂存配额默认 20 GiB，按文件声明大小的两倍预留组装空间。过期后每 15 分钟轮询处理最多 32 条记录，不保证恰在第 24 小时删除；指纹或权限异常的暂存记录保留等待检查，不能通过释放配额掩盖仍占用的磁盘。仅清理本服务的暂存记录，不递归清理云盘目录。

最终保存不覆盖同名文件。提交先记录 `COMPLETING` 再发布文件，结果不确定时页面只“检查保存结果”，不会自动重复写入。若进程在发布窗口退出，可能需要用户确认目标文件，服务不会冒险重放。这是本地磁盘续传，不是 S3/FTP/SFTP 的多段上传，也不代表跨实例恢复已经支持。

2026-10-12 收尾修正 Unix 的重命名竞争窗口：最终目标使用 `CREATE_NEW` 原子创建，再以有界缓冲复制，已有同名文件不会被此续传覆盖。复制期间目标可能短暂显示为未完成文件；异常保留目标及 `COMPLETING`，用户需核查，不能自动删除或重放。大文件需要额外一次磁盘复制，并在复制结束后重新核对授权。Windows 空 `fileKey` 使用规范路径与高精度创建时间；无法获得可信创建时间的文件系统仍拒绝续传。

目录密码的输入值及配置值不再进入调试日志；目录保护表达式无法解析时拒绝访问，由管理员修正规则，而不是跳过保护继续公开内容。

## 外部嵌入模型兼容配置

默认关闭，**不复用 DeepSeek 聊天密钥**。供应商须真正支持标准 `POST /embeddings`：

```json
{"model":"供应商的embedding模型","input":["待嵌入文字"],"encoding_format":"float"}
```

响应 `data` 每项包含完整、唯一的 `index` 和数值数组 `embedding`。base URL 填前缀，例如 `https://供应商/v1`，程序追加 `/embeddings`，不要填写完整 endpoint。只允许 HTTPS，不允许 URL 凭据、查询或片段，不跟随重定向。

服务器私有环境文件：

```dotenv
# 没有实际嵌入服务时保持 false。
STUDENT_CLOUD_EMBEDDING_ENABLED=false
STUDENT_CLOUD_EMBEDDING_BASE_URL=
STUDENT_CLOUD_EMBEDDING_API_KEY=
STUDENT_CLOUD_EMBEDDING_MODEL=
# 必须等于模型实际维度，支持 32–4096。
STUDENT_CLOUD_EMBEDDING_DIMENSIONS=1024
STUDENT_CLOUD_EMBEDDING_TIMEOUT_SECONDS=10
STUDENT_CLOUD_EMBEDDING_MAX_CONCURRENT=2
STUDENT_CLOUD_EMBEDDING_MIN_SIMILARITY=0.25
```

启用前确认资料外传许可、隐私条款及费用。每份资料最多前 64 段，每段 700 字符，16 段一个请求；整次索引共用 10 秒期限，不自动付费重试。向量保存在账号隔离的资料表，不缓存授权、原始文件、密钥或原始响应。

2026-10-12 收尾增加检索内存保护：每份向量 JSON 上限 1 MiB，高维模型会在调用前减少片段数，实际覆盖以资料说明为准。搜索从读取数据库到权限复核全程最多并发 2 次，繁忙时直接提示，不无限排队。先读取不含向量的文字索引，第二条查询在 SQL 中限制账号、资料 ID、长度及首查快照，最多读取 30 MiB 向量，不将旧的巨大索引先读入内存再丢弃。旧超限或已变化向量继续保留关键词检索，主动重新索引才可恢复语义检索。

旧资料不自动调用外部服务，主动添加/重新索引才生成向量；页面显示覆盖范围。改地址、模型或维度后旧向量不能混用。搜索只发送当前问题、不重新上传文档；合并语义与关键词排名后，返回片段前仍复核权限及完整文件指纹。模型未配置、超时、索引损坏时明确回退文字检索。分数不是准确率。

兼容配置及模拟响应测试已实现，**尚未验证真实嵌入供应商**。[DeepSeek 官方模型页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列出聊天模型，但未列出 embedding；Flash 当前价格低于 Pro，适合继续用于小芽对话，不因此具备嵌入能力。

## 部署边界

已提供四服务 Docker Compose、HTTPS 覆盖、私有就绪探针、持久卷、资源限制及只读验收脚本，见 [Docker 生产部署与验收](Docker生产部署与验收-20261011.md)。配置解析通过不等于镜像或服务器验收通过。

Agent 写入仍限定本地存储、显式确认、不覆盖已有文件；定时任务只生成预览，不无人值守批量删除。真实云服务、OCR、嵌入供应商、Docker 引擎及服务器负载仍需实测，不能用模拟结果保证上线并发能力。
