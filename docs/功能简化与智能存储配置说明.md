# 功能简化与智能存储配置说明

更新日期：2026-10-10。适用于当前开发目录，不表示已发布到服务器或已验证用户真实云存储。

## 1. 添加存储源：先识别，再确认

入口：管理员后台 → 存储源连接 → 添加存储源。

1. 在“存储目录或连接地址”中粘贴地址，点击“智能识别”，也可以按 Enter。
2. 查看识别类型和建议字段。普通 HTTP(S) 地址可能属于多种服务，需要自己确认类型。
3. 点击“按……填入”。页面加载该类型的参数定义，再填入可采用的字段，不会保存存储源。
4. 补充用户名、密码、访问密钥等认证信息，核对存储桶和路径。
5. 点击“检查填写”，修正提示；支持的类型还可手动点击“只读测试连接”，最后点击“保存设置”。

识别采用前端本地规则，不依赖 AI、模型密钥或 Redis，也不发送地址去探测服务。识别地址格式不能证明账号正确、网络可达或具备读写权限。

### 可以识别的输入

| 输入示例 | 识别与填入 |
| --- | --- |
| `/data/student-files` | 本地存储，填入服务器目录 |
| `D:\student-files` | 本地存储，填入 Windows 绝对目录 |
| `\\server\share\files` | 本地存储，填入 UNC 目录；实际挂载和访问权限仍需自行确认 |
| `ftp://files.example.com:2121/course` | FTP，拆分主机、端口、基路径 |
| `sftp://files.example.com:2222/course` | SFTP，拆分主机、端口、基路径 |
| `webdavs://dav.example.com/course` | WebDAV，转换为对应的 HTTPS 连接地址 |
| `https://study-bucket.oss-cn-hangzhou.aliyuncs.com` | OSS，Bucket 为 `study-bucket`，Endpoint 为 `oss-cn-hangzhou.aliyuncs.com` |
| `https://storage.example.com:9000` | MinIO、S3、WebDAV 等候选；不会仅凭端口判定类型 |
| `storage.example.com` | 可能的 S3/WebDAV 主机；不自行猜测连接协议 |

OSS 目前识别经典官方域名，不将自定义域名、其他云厂商或对象下载链接强行猜成 OSS。Bucket 与 Endpoint 分开填写，避免重复拼接。规则依据见[阿里云官方 Bucket 域名说明](https://help.aliyun.com/zh/oss/user-guide/access-oss-via-bucket-domain-name)。

本地目录是**部署服务器或 Docker 容器中的目录**，不是打开网页那台电脑上的文件夹。识别不会创建目录，也不会检查目录是否存在。Docker 部署时应填写容器挂载后的路径。

### 不会采用的内容

- 地址中的用户名、密码、访问密钥、签名查询参数、片段和路径穿越内容。
- 服务端未开放的存储类型。
- 当前参数定义中不存在、隐藏或属于密钥的字段。
- 根据域名或端口猜出的地域、桶名、访问权限。

输入改变后，旧候选立即清空。加载参数失败时不填入建议，重新加载后可再次采用。切换页面、账号或关闭页面后，迟到的识别填入不会落到另一个存储源。

## 2. 表单更简洁

- 常用方式保留本地目录、OSS、S3、MinIO、WebDAV、SFTP 卡片；其他后端支持的类型仍在下拉框中。
- 常用连接信息优先展示，有有效默认值的技术参数折叠到“高级设置”；不是删除字段。
- 新建时建议一个存储源名称；已经手动填写的名称、别名不因识别而改写。
- 别名选填，留空由后台分配。
- 普通密码、密钥输入默认遮蔽，允许显式查看；某些现有多行私钥输入仍是原来的文本框，不能将其当成安全保管库。
- 切换存储类型会清除上一种类型的连接参数和认证信息，避免把旧凭据串入新的配置。
- 保存期间禁止重复提交；超时后的结果可能不确定，应先回列表核实，不应反复点击。

“检查填写”只检查必填项、路径、URL、端口等本地格式，不会保存，也不是实际连接测试。新增独立的只读连接测试：本地类型检查服务器目录属性；S3/OSS/MinIO 等兼容类型在公网端点读取最多一项元数据。只读测试不调用保存、上传或跨域写接口。其他协议及私网端点暂不支持该独立测试，不应绕过出站地址限制。详细边界见[本轮实现与回归说明](业务优化实现与回归说明-20261010.md)。

## 3. 存储桶与跨域配置

对于 S3 类配置，补齐必要字段后，可以显式点击“读取存储桶”或“查看远端跨域配置”。输入密钥本身不会自动调用这两个读取接口。

- 这些是用户主动发起的只读辅助查询，不代表上传权限已验证。
- 没有列桶权限时，可继续手动填写桶名；读取失败不会清空手工填写的桶名。
- 读取到的跨域信息只展示，不覆盖表单，不自动写回远端桶。
- 辅助读取接口有出站地址限制，不支持私网端点。不要因此绕过安全限制；按实际部署网络配置源，并核对后台保存结果。

**保存和后端重启不再自动应用远端跨域规则。** 保存仅保留规则配置；在已保存的存储源编辑页点击“应用已保存的跨域规则”，再次确认后才写入远端桶。该操作使用后台已保存的连接和规则，不提交未保存的表单内容；受公网出站地址限制。结果不确定时先查看远端规则核实，不应反复点击。

旧响应中的跨域 JSON 字符串会转换为数组再显示；损坏的配置会阻止编辑保存，不静默丢弃原规则。

## 4. 自动化工作台与小芽

这部分是前一阶段的功能简化，与存储源识别独立。

- 文件页“整理此目录”携带当前存储源和目录进入工作台，不需要重新填路径。
- 工作台以三个任务入口为主：文件分类整理、批量重命名、课程资料归档。
- 小芽顶部提供上传、整理、重命名、归档快捷入口。整理和重命名快捷入口直接生成预览，不必等待模型回答。
- 上传仍需要选择文件和核对目标；网页不能未经选择读取电脑任意文件。
- 文件变动先生成任务预览，用户确认后执行；历史任务详情默认折叠，失败步骤保留可见。
- “再做一次”仅重新填入表单，不直接重放历史文件操作；重试生成的新任务也需要确认。
- 支持的本地文件移动或重命名完成后通知文件页刷新；新打开历史已完成任务不会重复触发。
- 定时任务按既有启用规则运行，仍受当前账号、目录和存储权限约束；不提供任意系统命令或跨用户越权执行。

课程和定时任务列表按需读取，重复打开复用已加载数据；独立失败可单独重试。请求取消和晚响应保护避免账号或目录切换后显示上一处的数据。小芽形象未修改。
