# 账号权限管理调整

## 使用方式

2026-10-24 起，成员权限由所属工作空间管理员设置，全局管理员不再设置任何成员的存储授权。

1. 使用普通管理员（`TENANT_ADMIN`）登录，进入 `/workspace-admin`。
2. 在成员列表选择具体已入会的普通成员，点击“设置权限”。
3. 逐项设置该成员的存储源启用、授权根目录和文件操作权限。只能授予管理员本人当前在同一空间拥有的存储源、根目录或其子目录、常规操作权限；不允许授予忽略目录密码或隐藏规则的例外。
4. 保存后仅更新选中成员、提交的存储源行和默认权限；没有提交或当前管理员无权管理的历史授权保留。撤销某个源时关闭该行“允许使用”。

待审批、被拒绝的成员不提供该入口，审批仍由空间管理员处理。后端继续校验成员加入状态，不通过启用或权限修改绕过审核。

“新增存储源默认权限”只属于当前选定账号，用于以后新增存储源时的既有自动授权策略；它不会修改该账号当前各存储源的具体授权。本轮没有擅自更改其他成员的未来自动授权策略。

## 全局管理员

- 账号页只编辑用户名、昵称和密码，状态固定启用，不再展示默认权限和存储授权编辑器。
- 全局账号资料编辑不再读取、显示或提交成员权限。`/admin/user/saveOrUpdate` 拒绝任何非空值的 `defaultPermissions` 或 `userStorageSourceList` 字段（空集合也拒绝），不会把空列表当成撤销成员全部授权。
- 后端不接受通过账号保存接口停用、降级全局管理员；传入的存储授权、根目录、默认权限不能降低其固定权限。
- 修改资料不删除或重写历史存储授权行。运行时按真实授权主体的最新角色计算有效权限：启用的全局管理员对启用存储源使用 `/` 根目录及全部常规文件权限，不要求预先添加授权行。
- 权限映射、存储列表、目录新鲜度校验和分享者授权使用一致规则；管理员权限不写入普通账号授权缓存，旧缓存不会阻止管理员访问，也不会在角色变化后把管理员权限留给普通账号。
- 最高常规权限不等于关闭安全检查：不自动授予忽略密码或忽略隐藏，源停用、分享选择范围和分享所属空间状态等原有检查保留；存储驱动和文件系统本身的权限也不会被绕过。
- 不因此授予读取其他用户私人 AI 记忆、课程记录等账号私有数据的权限。

## 旧模板与前端防误操作

移除“新账号默认权限”全局导航，账号编辑页拒绝模板 `0` 和退役匿名记录 `2`。后端管理详情、保存和状态修改不再将模板 `0` 当作可编辑账号。没有删除其历史数据；单点登录内部兼容注册仍保留，不把它冒充邮箱注册策略。

全局账号创建仍需选择所属空间，保存仅发送账号资料字段，不回传密码盐、邮箱、账号唯一 ID、成员审批状态或授权集合。空间成员权限面板在切换成员、退出登录或角色变化时取消旧请求并清除旧数据。

空间权限接口为 `GET/PUT /api/workspace-admin/members/{id}/permissions`。后端每次验证操作者当前角色、空间状态、成员归属和审核状态；全局管理员、普通成员、其他空间管理员、自身和其他管理员账号均不能通过此接口修改授权。保存后清理该成员的权限缓存，撤销在下一次文件访问时生效。
