# 4.6.0 课程资料库：设计、使用与验收

日期：2026-09-23。适用于 `feature/learning-library` 分支。

## 1. 本次完成的范围

在现有三角色云盘上增加面向本科课程学习的资料组织与问答证据检索。不是自研大模型，不宣称模型训练，也没有引入向量数据库。这是“文本提取 + 关键词片段检索 + Agent 工具调用”的实现，可作为毕设中独立说明、演示和测试的模块。

普通用户和系统管理员各自管理私人课程库；访客无权使用。管理员没有通过学习接口读取其他账号索引的特权。原有云盘目录与分享权限继续生效。

## 2. 使用步骤

1. 登录，先在云盘中上传学习资料。
2. 点击顶部“课程资料”，或访问 `/learning`。
3. 创建课程，填写名称与学期。可按学期筛选，修改名称，或删除课程。
4. 点击“从云盘添加资料”，选择有读取权限的本地存储和文件，可填写逗号分隔的标签。
5. 确认建立索引。可以按文件名或标签筛选，也可以输入关键词检索本课程正文。
6. 向小芽提出课程资料问题，例如“在我的课程资料中查找数据库事务的定义”。小芽可调用资料检索工具，返回带 `[M资料编号-S片段编号]` 的回答；展开“本轮资料依据”可查看实际摘录。
7. 文件修改后点击“重新索引”。文件被移动或改名后需重新添加新路径并移除旧索引。

移除索引或课程不影响云盘原文件。资料列表的“所在目录”返回原文件所在位置。未配置模型密钥时，课程管理及正文检索仍可独立使用。

## 3. 数据与接口设计

| 表 | 主要字段 | 用途 |
| --- | --- | --- |
| `learning_course` | id、owner_user_id、name、semester | 私人课程分类 |
| `learning_material` | id、owner_user_id、course_id、storage_key、path、name、tags、content、fingerprint、indexed_at | 文件引用、有限长度的提取文字与版本指纹 |

`owner_user_id` 由服务端当前登录身份填写，客户端不能指定。每个课程／资料查询、更新、删除均限制所有者。`content` 和 `fingerprint` 不出现在普通列表或创建接口 JSON 中，只有经过重新鉴权的检索返回有限的匹配片段。

| 方法及路径 | 功能 |
| --- | --- |
| GET / POST `/api/learning/courses` | 列出／创建自己的课程 |
| PUT / DELETE `/api/learning/courses/{id}` | 修改／删除自己的课程 |
| GET `/api/learning/materials?courseId=…` | 课程资料列表，不返回全文 |
| POST `/api/learning/materials` | 验证云盘读取权限、提取文字并索引 |
| POST `/api/learning/materials/{id}/refresh` | 重新提取与计算指纹 |
| DELETE `/api/learning/materials/{id}` | 仅删除索引 |
| GET `/api/learning/search?query=…&courseId=…` | 可选课程范围的私有片段检索 |

上述接口均要求登录；索引、刷新与检索各有每 IP 每分钟 20 次的请求限制。Agent 对话保留其已有频率限制。

## 4. 检索过程与安全边界

1. 检查账号及工作空间仍启用，拒绝访客和权限模板身份。
2. 按当前账号读取索引；可选课程 ID 也必须归该账号所有。
3. 针对每份资料重新检查存储源、用户根目录及预览／下载权限。
4. 检查文件和祖先目录的隐藏、禁止访问、禁止下载、密码规则；不会保存密码或请求模型提供密码。拥有原系统忽略规则权限的账号仍按该权限处理。
5. 将用户相对路径限定在本地存储及其授权根目录下；拒绝目录跳转、符号链接越界、绝对磁盘路径等。不通过任意 URL 抓取资料。
6. 重读文件并计算 SHA-256。大小和修改时间相同但内容变化时也会跳过旧索引。文件删除、权限撤销、规则更改后不返回旧正文。
7. 用中文双字片段和英文词作为关键词，对 700 字符、步长 600 的文本片段计分，最多返回 5 个片段；这不是语义向量搜索。文件名和标签也参与匹配。
8. 引用卡片由实际工具结果生成，不从模型文本解析或信任模型编造的来源。无命中时服务端给出“未检索到足够依据”的提示。

这不是对模型正确性的保证。答案仍需人工对照引用；文本片段号不是 PDF 页码。文档中的指令按不可信内容处理，但提示词防护不等于彻底解决提示注入。

被撤销权限的索引不会继续输出正文，但数据库中已保存的提取文本不会因为源文件改动自动物理删除。可以主动移除索引；删除课程会清理其索引，删除账号会同步清理该账号的课程和索引。已展示的回答、历史对话及备份也不能被权限撤销追溯收回。

## 5. 资源限制与已知限制

- 每个账号最多 50 门课程、30 份资料；每份文件最多 5 MB。适用于单实例、小规模毕设演示，不作为分布式严格配额方案。
- 索引格式为 UTF-8 TXT / MD、文本 PDF、DOCX。PDF 只提取前 30 页，文字最多保存 12,000 字符；截断时保留提示。扫描件需要先做 OCR，本项目未提供 OCR。
- 当前仅支持本地存储。第三方对象存储、网盘仍能使用原有云盘功能，但暂不支持学习资料索引。
- 搜索会检查本人最多 30 份资料的内容指纹，属于同步、小规模检索；没有异步任务、向量检索或大规模性能承诺。
- 引用摘录在使用小芽时会被发送到管理员配置的模型服务。添加资料前页面会提示这一点；敏感资料不应交给未经允许的外部模型。
- 文本索引存于数据库，尚未做应用层加密；数据库账号、备份和管理员运维权限应按包含用户资料正文的标准保护。
- 旧项目的完整 ESLint 历史问题、大体积预览模块、第三方服务接入与真实在线模型效果仍需专项工作。

## 7. 升级、分支与回滚

先备份业务数据库和用户文件，再停止旧服务、构建前后端、替换 JAR 与前端 dist。4.6.0 首次连接 V60 数据库时，Flyway 自动运行 V61，仅新增课程和资料两张表；不需要执行重建 SQL。数据库账号需具备建表权限。使用新目录 `backend/`、`frontend/` 更新脚本、IDE 和服务配置；启动命令见 [前后端启动说明](../前后端启动说明.md)。

不要修改已经应用的 V1–V60。V9、V11 中残留的历史域名是旧迁移内容，V59 已清理运行配置；保留这些脚本用于升级校验。界面、包名、当前路径使用学生云盘命名，来源说明及原作者许可保留。

本次不强制推送、不改写历史、不自动合并 `main`。新功能在 `feature/learning-library` 分支；确认浏览器验收与真实模型评估后，再决定合并及正式发布。回滚需同时恢复对应版本的应用、前端及数据库备份，不要随意删除 Flyway 历史或手工改校验值。
