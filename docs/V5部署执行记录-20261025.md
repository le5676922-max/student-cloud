### 网关边界修复

正式复核发现：带 `Accept: text/event-stream` 的未登录流式请求，在 Spring 异常处理器返回 JSON 时发生媒体格式不匹配，形成空的 HTTP 500。V5 部署的 AI 子路径代理已增加 `proxy_set_header Accept "*/*"`，允许后端序列化 JSON 错误；成功流式控制器仍显式产生 `text/event-stream`，其关闭缓冲和 gzip 的设置保留。

这是 V5 的部署配置覆盖，记录在 `docker/v5/nginx/routes.conf`，与前端通用 Nginx 源码快照有这一处有意差异。上线后已在真实匿名请求上确认 401；Nginx 语法通过。没有覆盖已发布镜像标签或改变镜像 digest。完整登录后的 AI 流式对话仍需使用真实账号进行功能验收，不能把匿名验证当作模型完整业务验证。

## 用户指定本地云盘目录

上线后用户在本地云盘表单填写 `/date/file`，服务端检查发现该路径在宿主机／容器均未准备，初始化报“路径不存在”。页面因此同时显示保存结果未确认及只读检查失败。只读查询确认失败后未留下对应的存储源记录，未直接修改业务数据库。

用户随后明确要求创建这个目录，已按原样使用 `/date/file`，没有替换成其他路径。服务器创建目录时核验父目录与目标不是符号链接，目标权限设为 `10001:10001`／`750`，在 V5 Compose 中新增 `/date/file:/date/file` 的持久绑定挂载。应用该挂载需要重建一次后端容器，保持原镜像 digest、数据库、课程区和续传暂存区不变；Nginx 在后端就绪后重新加载上游地址。管理员需要重新登录，再在界面测试和保存该云盘配置。

挂载完成后，实际以容器运行用户 UID 10001 在该目录创建随机合成测试文件、读回比较并删除，三步均通过；确认该目录为可写宿主机绑定挂载。后端已 healthy，Nginx 配置检查与公网 16 项只读冒烟复测通过。日志：本机工作区 `.codex-tmp/v5-local-storage-mount-20261025.log`。
