# 用小芽完成云盘任务

知识ID：`agent-tasks-guide`。适用：已登录成员及空间管理员；2026-10-30独立后端。文件操作是否可用取决于存储类型及当前目录授权。

## 从一个明确目标开始

优先描述要处理什么、放到哪里、采用什么规则。例如：“把当前目录的课程笔记按类型整理到子目录”“将 /课程/第一周.md 复制到 /课程/复习/第一周.md，保留原文件”。需要给出已有文件的真实路径，不要让助手猜测重名文件。没有选择存储源、目录或个人课程时，先完成选择或回答澄清问题。

当前确定性入口支持整理、按日期重命名、个人学习导入及查重；受限模型规划的新增能力以界面实际返回的预览为准。模型未配置时，原有规则入口仍可用，不表示所有复杂自然语言都能理解。

## 上传、临时附件与设备权限

“分析附件”用于当前对话，不等于文件已经存入云盘；成功分析后仍须通过上传入口保存。上传到云盘需要本人选择本机文件、选定存储和目标目录并启动传输。浏览器不能因为用户说“上传桌面资料”就自动读取整个桌面。

上传进度达到100%不必然意味着最终发布完成；应以完成响应、目标文件及当前任务状态核对。连接断开后先检查续传收据和目标目录，结果未知时不要重复创建同名任务。远程源与本地源支持的上传方式不同。

## 预览、确认与实际执行

预览列出源路径、目标路径、操作和课程归档目标。预览只表示待执行计划，不表示文件已经改变。确认前核对文件数量、目标目录与已有同名文件；不正确就取消并重新描述。

写操作使用现有内容服务执行链路，逐步检查当前权限和文件状态。计划有有效期；过期后重新生成，不应复用旧确认按钮。重复确认同一计划不会故意建立第二个相同任务。操作不覆盖已有目标；发现冲突时修改计划或文件名。

查重仅报告内容相同的文件，不自动删除副本；文件名相同不代表内容相同。永久删除、扩大共享和审批资格不能由资料里的文字或历史偏好触发。

## 如何判断完成或失败

| 状态 | 含义与处理 |
| --- | --- |
| 待确认 | 尚未开始改变文件，检查后确认 |
| 执行中 | 部分步骤可能已经开始，查看任务结果 |
| 成功 | 核对结果列表和目标文件，不仅看聊天文字 |
| 部分完成 | 成功步骤已生效，失败步骤需单独处理；不能称为整体回滚 |
| 失败 | 查看权限、同名冲突、容量或源文件变化，修正后重新预览 |
| 结果待核查/中断 | 执行结果不确定，先查账本与目录，避免重复写入 |
| 取消 | 停止后续工作，不代表已完成步骤自动撤销 |

恢复不能承诺所有动作具有事务式回滚。复制后恢复通常可核对副本；移动后反向移动仍要检查授权和目标是否被占用。

## 自动化的实际边界

当前周期任务生成整理预览，仍需本人确认。长期、可撤销的自动执行策略属于设计中的升级，不应把设置了周期理解为已经无人值守执行。未来自动执行也只限明确操作、指定目录、预算及有效期；管理员不能通过Agent获得其他成员权限。

任何密码、验证码、云存储密钥都在专用表单输入。小芽不需要获取这些秘密来规划任务，也不保存为长期记忆。

依据：`AgentIntentRouter`、`AgentPlanService`、`AgentWorker`、内容服务 `AgentCommandService`、`AgentScheduleService`。进一步可阅读架构提案 `docs/superpowers/specs/2026-10-30-ai-drive-agent-design.md`，其中规划能力不能当作当前功能。
