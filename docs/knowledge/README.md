# 小芽知识库：资料与使用手册

这组文档是2026-10-30核对的**产品知识种子**，供用户阅读、开发维护及检索评测。它们不包含成员私人文件，不代表已经实现任意课程的自动Wiki编译或模型微调。

当前运行时的产品帮助来源是独立智能服务的 `src/main/resources/ai/knowledge/project-help.json`。这里提供更完整的流程说明；修改业务时须同步修改运行时条目与评测。原始源码、接口和回归测试优先于历史计划。

| 阅读目标 | 文档 |
| --- | --- |
| 让小芽执行任务，判断什么时候需要本人操作 | [任务操作与结果核验](agent-tasks.md) |
| 注册、加入空间、邀请成员与安全找回密码 | [账号与成员](accounts-and-members.md) |
| 云盘连接、容量、上传与下载故障 | [文件与存储](files-and-storage.md) |
| 个人学习和共享课程的不同用法 | [课程资料](courses-and-materials.md) |
| 资料检索、引用、长期记忆和知识更新 | [知识与记忆](knowledge-and-memory.md) |
| 没有解决、人工支持与知识审核 | [反馈与改进](feedback-and-improvement.md) |

每页均区分实际能力与后续设计。知识可以详细，助手默认回答仍应简洁：结论、必要步骤、真实来源或执行结果即可；用户要求时再展开说明。

维护规则：不填写密码、验证码、API密钥、私有Token或服务器实际凭据；不把管理员可管理账号理解为可代替成员读取私人资料；不把模型的“已经完成”文字当作业务执行凭证。
