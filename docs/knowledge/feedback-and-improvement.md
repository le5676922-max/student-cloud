# 未解决反馈、人工支持与知识改进

知识ID：`feedback-improvement-guide`。适用：成员提交反馈；全局管理员处理知识与人工支持。2026-10-30独立后端。

## 点击“没有解决”之后

选择本轮完整回答的未解决入口，后端登记实际问题、回答、消息及必要范围信息。相同消息重复提交应返回原记录而不是生成多份工单。反馈不等于立即转人工，也不等于答案被认定错误；无法定位完整回答时先刷新并核对。

只提交为解决问题所需的内容，不把密码、验证码或云存储凭据贴入反馈。含私人资料的回答可以用于处理该问题，但不能因管理员修订过文字就自动变为全站可共享知识。

## 人工支持如何使用

需要人工时，在助手内选择人工支持并确认。管理员离线时可以留下问题等待回复，系统不能假装已接通在线坐席。不需要让每一个提问都转人工；文件路径不明、无资料或暂时缺授权时，先由助手澄清或说明限制。

人工服务不能替用户完成邮箱验证，也不能要求用户把验证码发来。管理员解决权限、配额或课程问题时仍遵守对应角色与课程创建者边界。

## 管理员整理知识

进入全局反馈管理→读取完整问题和当前版本→调查原因→填写正确答案与处理说明→保存修订→需要时用AI润色→本人核对→标记已解决→选择允许的发布范围。AI润色是草稿，不能自动覆盖他人刚保存的修订或跳过人工审核。

“已解决”与“已发布”是两个状态。课程来源只能发布回原课程，空间内容不能跨空间发布，涉及个人附件/记忆/私有对话的来源不能直接发布共享知识。发布全站知识需要明确核对通用性和来源；隐去名字也不自动消除资料的隐私属性。

发布使用版本检查，冲突时重新读取；重复发送相同已成功发布命令可幂等处理，不能把过期编辑覆盖最新版本。发现错误时撤回活动知识，保留历史，重新审核后发布新版本。

## 语料导出和评测

已解决反馈不能直接等同训练语料。新版导出只允许当前活动的全站审核知识、修订内容及来源版本一致、来源可发布的条目；未发布、空间或课程范围、撤回、旧版本以及无法证明来源的记录不进入导出。导出也不代表已经完成脱敏或已获外部训练授权。

评价闭环应包含：该错误在相似问法中是否修复、是否仍能正确拒绝无权限资料、是否没有影响其他角色、引用是否还有效，以及答案是否简洁。安全回归失败时停止候选发布，不能只统计用户点赞率。

## 报告故障的有效信息

提供页面/功能、操作时间、预期与实际结果、请求状态码以及任务或反馈标识即可；截图先遮盖密钥和私人文件内容。管理员日志按标识关联服务，记录问题原因与修复验证，不采集整盘内容来排查一个按钮问题。

依据：`AnswerFeedbackService`、`ChatAnswerStore`、`ReviewedKnowledgeService`、`AnswerFeedbackController`及人工客服WebSocket业务。
