# AI 回答反馈与人工整理

> 本文记录 V75 初版行为与当时测试。V78 已补充 AI 润色、明确审核发布、版本及撤回；首次未解决不自动提示转人工。当前使用方法以[最新操作说明](云盘课程与知识改进操作说明-20261025.md)及[知识库整理发布](知识库反馈整理与发布.md)为准，以下历史测试数字不代表本轮最终验收。

成员认为小芽的真实模型回答没有解决问题时，可以点击回答下方的“没有解决？”。按钮旁会注明“提交本轮问答，供管理员改进知识库”；点击后提交当前这一轮的问题和回答供全局管理员复核，并显示独立的转人工确认卡片。服务器不会自行收集完整历史、附件、长期记忆、文件内容或工具结果。

反馈与转人工客服是两条独立流程：点击反馈按钮即提交本轮问答，只有再点击“确认转人工”才创建客服会话。取消转人工不会撤回已经提交的反馈，也不表示反馈未保存。提交过程中会显示“正在记录…”，成功后显示“已记录反馈”；失败时可以重试，不能把失败或未知结果当成已保存。

## 角色与数据范围

- `USER` 和 `TENANT_ADMIN` 可以提交反馈。用户 ID 和所属空间由当前登录身份决定，客户端不能指定。
- 只有 `ADMIN` 可以查看全站反馈、读取详情、整理正确回答、标记状态和导出。普通成员、空间管理员和匿名请求均不能读取这个全局队列。
- 来源固定为 `userSubmitted`，表示用户主动提交的文本。客户端可以修改文本，管理员不能把它当成经过服务器验证的原始聊天记录。
- 已提交的原问题和原回答不会因管理员整理而被覆盖。正确回答及处理备注独立保存。

## 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/ai/feedback` | 提交 `{clientMessageId, question, answer, pagePath?}` |
| `GET /admin/ai-feedback?page=1&pageSize=20&status=OPEN` | 分页队列；状态可省略或为空 |
| `GET /admin/ai-feedback/{id}` | 查看完整反馈和人工整理内容 |
| `PUT /admin/ai-feedback/{id}` | 提交 `{status, correctedAnswer, note}` |
| `GET /admin/ai-feedback/export` | 导出最多 500 条已整理问答 |

`question` 上限 2000 字符，`answer` 和 `correctedAnswer` 上限 12000，`note` 上限 2000，页面路径上限 500；页面路径只保存查询参数及片段之前的部分。同一用户使用相同 `clientMessageId` 重试相同内容只保存一次，改动内容后复用旧标识会被拒绝。列表每页最多 50 条，不返回完整原回答。

状态为 `OPEN`（待处理）、`RESOLVED`（已整理）、`DISMISSED`（不采纳）。标记 `RESOLVED` 前必须填写非空的正确回答。列表按提交时间倒序，导出按最近整理时间倒序。

## 如何改进知识库

全局管理员从后台“日志与诊断”的“AI 回答反馈”进入 `/admin/ai-feedback`，先核实问题与事实，再填写可靠的正确回答。原 AI 回答默认折叠并标注待核验，不会自动填入正确回答。只有 `RESOLVED` 且正确回答非空的记录才会进入导出。

导出接口返回 `[{question, answer}]`，后台下载时生成 JSONL 文件，每行是一组问答；其中 `answer` 是人工整理后的答案，不是原始错误回答。不带用户 ID、账号、空间、路径、备注或时间等身份元数据，一次最多 500 条。

导出供人工整理知识资料使用，不会自动发布为项目知识库、调用外部模型、创建向量或启动付费微调。正文仍可能含用户主动写下的姓名等个人信息，导入或分享前需要人工复核，不能把去除身份元数据当成完全匿名。

系统在保存和导出前会遮盖常见的 `sk-` 密钥、Bearer 令牌以及 `password=...` 等敏感值格式。这是有限的格式识别，不是识别所有秘密的保证。

## 数据库与运行版本

新增 MySQL / SQLite 的 V75 迁移，只创建 `ai_answer_feedback` 表及索引，不重建业务数据库。删除提交账号会清理其反馈；删除复核账号时只移除复核人关联，不删除其他成员的反馈。

2026-10-25 本机已从当前编译后的源码类启动后端，连接 MySQL 8.0，由 Flyway 将已有 V74 升级到 V75，启动日志确认迁移成功。前端通过 Vite 开发服务运行。未生成新 JAR、生产前端包或部署到服务器；其他环境仍须运行包含 V75 的后端，只刷新前端不能增加接口。
