# 全局管理图表设计参考

参考源为 [Soybean Admin 的首页模块布局](https://github.com/soybeanjs/soybean-admin/blob/main/src/views/home/index.vue)，以及它将趋势图、分类占比分为独立模块的组织方式；该仓库采用 [MIT 许可证](https://github.com/soybeanjs/soybean-admin/blob/main/LICENSE)。本项目保留 Vue 3 / Element Plus 及原有界面主题，没有复制其模拟业务数据或切换 UI 框架。

当前已经接入的图表使用现有全局汇总接口的数据：空间管理员／普通成员构成、云盘启用状态、工作空间状态和七天登录趋势。图例可高亮分类，图表可切换到表格明细；未知数据不按零展示，日志关闭也不冒充真实零登录。云盘“已启用”仅代表配置开关，不冒充已验证连接成功。

图表使用本项目自行实现的 SVG 与 Vue 组件，按需加载，没有增加第三方前端依赖。原有四类统计复用全局总览响应；业务图表通过一个 `/admin/business-metrics` 聚合接口读取云盘类型、三类待审批事项、反馈状态、知识发布范围、课程规模与前十工作空间课程用量，最多缓存30秒。每次读取先重新校验全局管理员身份，筛选只传空间ID，不拉取全量成员和文件。

课程用量来自实际账本；个人云盘全站实际占用尚未统一计量，明确展示未知。新接口与图表分别覆盖真实临时SQLite查询、Vue/JSDOM交互，真实MySQL HTTP工作流另行记录在本轮验收报告；没有用演示数字代替业务数据。手机布局、减少动画设置和语义明细表保留，不把组件测试描述为已经完成所有设备的人工视觉验收。

本次按 reverse-engineer-anything 技能的源代码分析边界直接核对 GitHub 源码，未运行不相关的二进制逆向引擎，也未将静态源码检查描述成外部演示站的运行观察。
