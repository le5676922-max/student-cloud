# 小芽知识库内容与维护手册

本文对应正在开发的独立微服务后端，保留现有网站界面。以下说明以实际已实现接口为依据，不表示已经部署到线上。

知识库采用项目说明、人工审核知识和用户授权的课程片段共同检索。它改进的是检索依据和回答流程，不是训练模型参数。

内置说明版本：`2026-10-27-independent-remote-v2`；共 **42** 个主题。

## 使用流程

1. 在助手中提出具体问题，可选择简洁或详细回答。询问网站功能时使用内置项目说明；不会为读取这些公开说明扫描个人云盘。
2. 需要课程资料时先选择个人课程，并勾选本轮使用私有资料。引用只代表检索到的片段，不代表模型读完所有文件。
3. 需要文件操作时进入目标云盘目录，发送整理、日期命名等明确指令。核对预览并确认后才会执行；查询操作方法不会触发执行。
4. 回答未解决问题时点击“没有解决”。系统记录本轮真实问答，全局管理员可查看和整理。提交反馈不会自动转人工或发布知识。

## 完整知识说明

### 1. 学生云盘功能与独立后端支持范围

适用角色：成员、空间管理员、全局管理员。

学生云盘用于按账号和空间授权管理学习文件。当前独立后端支持 LOCAL 本地存储的目录浏览、上传下载、新建目录、重命名、复制移动、回收站、受控分享、个人学习资料索引、共享课程以及小芽助手；已实现阿里云 OSS、S3 兼容存储和 MinIO 的远程列表、读取、新建目录和上传。远程复制、移动、重命名、删除、回收站和分享尚未开放。文件可见范围由后端逐次检查，加入空间并不自动取得云盘根目录。

个人学习页 /learning 管理本人资料引用；共享课程页 /courses 管理受成员资格保护的课程；/agent-tasks 查看操作预览和执行结果。功能是否可用还取决于管理员配置、目录授权和服务状态；源码中的功能不表示网站已经部署了相同版本，也不表示已通过真实云账号验收。

### 2. 全局管理员、空间管理员和普通成员的权限区别

适用角色：成员、空间管理员、全局管理员。

ADMIN 是全局管理员，负责平台账号、空间和受控本地存储治理；TENANT_ADMIN 是空间管理员，处理本空间普通成员、加入申请和云盘使用授权；USER 是普通成员，只能使用已获授权的目录和已加入的课程。空间管理员使用 /workspace-admin，全局管理使用 /admin。

管理员角色不会自动赋予他人的个人课程索引、长期记忆或私人云盘读取权。遇到文件无权限，应核对空间、存储和目录授权；不要通过提升为全局管理员来代替成员授权。

### 3. 邮箱或账号登录及登录失效排查

适用角色：成员、空间管理员、全局管理员。

在 /login 使用邮箱、系统分配的账号 ID 或兼容用户名和密码登录；空间名称不是登录账号。注册后请保存页面返回的账号信息。账号、所在空间或成员加入状态不可用时，即使密码正确也可能无法使用相应业务。

出现登录过期时重新登录；重置密码会撤销旧会话。不要向助手或其他人发送密码、验证码、登录 Token。所有文件访问和受控分享都要求有效登录，分享地址不能代替身份验证。

### 4. 注册空间管理员并创建工作空间

适用角色：成员、空间管理员。

登录页的公开注册是否开放由平台配置决定。空间管理员注册需要验证邮箱，填写账号资料和空间信息；成功后成为自己空间的管理员。空间名称用于识别空间，不是账号登录凭据。

创建空间不等于分配服务器磁盘，也不会自动开放所有存储。需要使用本地云盘时，再由空间管理员提交用途和容量申请，等待全局管理员批准。页面提示邮箱功能未配置时，应联系平台管理员，反复请求验证码无法补足 SMTP 配置。

### 5. 成员通过邀请码或空间名称加入工作空间

适用角色：成员、空间管理员。

成员可以按注册页提示验证邮箱后加入已有空间。使用有效空间邀请码时按邀请规则加入；按空间名称申请则需要对应空间管理员审核。等待审核不是密码错误，应由目标空间管理员处理加入申请。

加入空间只建立成员归属，不自动获得成员目录或上传容量。加入完成后仍需在“申请云盘 / 查看容量”申请具体存储，获批后才能按授权浏览和写入。不要把共享课程邀请码填入空间加入入口，两类邀请的用途不同。

### 6. 忘记密码、收不到验证码与账号安全

适用角色：成员、空间管理员、全局管理员。

忘记密码时使用网站的邮箱找回入口，按当前页面完成验证码和新密码校验。确认邮箱拼写、垃圾邮件目录及请求间隔；验证码有使用目的和有效期，注册验证码不能冒用于找回密码。成功重置后原登录会话失效，需要重新登录。

若页面提示邮件未启用、发送失败或服务暂不可用，需由平台管理员检查独立后端 SMTP 配置和实际投递。助手不能读取验证码或代发验证邮件，也不应宣称未验证的 QQ SMTP 一定可用。

### 7. 首页没有文件、存储源或可访问目录怎么办

适用角色：成员、空间管理员。

先确认已经登录到正确账号和工作空间，再查看存储源选择器。普通成员只会得到已启用且明确授权的存储和个人目录；没有存储源通常需要申请云盘或由空间管理员检查授权。存储源存在但目录为空，也可能只是当前个人目录尚无文件。

不要把空白页面直接判断为资料丢失。核对目录路径、存储源启用状态、成员授权和读取权限；账号或空间停用、授权撤回及服务故障都会影响访问。管理员无法以关闭鉴权的方式替代授权。

### 8. 普通成员申请云盘容量与上传权限

适用角色：成员、空间管理员。

普通成员从“申请云盘 / 查看容量”（/cloud-access）选择本空间存储并提交申请。对应空间管理员审核后，授予账号专属目录、容量和是否允许上传；其他成员不会因此看到该个人目录。工作空间成员身份本身不包含云盘根目录权限。

容量按每个账号在每个存储源上的授权分别计算，界面显示单位与后端字节预算以页面为准。额度为零或写入权限关闭时不能新增文件；上传、复制、移动和续传最终完成都要再次检查权限与容量。

### 9. 上传和下载文件的步骤与50MiB限制

适用角色：成员、空间管理员。

打开已授权的存储源和目标目录，再使用上传按钮或拖入文件；先确认目标目录具有上传权限和足够容量。独立后端 LOCAL 文件单次传输上限为50MiB，LOCAL 分片续传也沿用单文件50MiB上限，不能通过分片绕过限制。OSS/S3 远程源使用登录态代理上传，单文件须在1字节至50MiB之间；读取上限50MiB。远程上传还要求连接已完成读写验证并保存，且成员当前获准上传。

下载需要当前读取权限，文件详情或列表中的下载操作仍会由后端核验身份。上传失败先看目录授权、同名冲突、容量和错误提示；写入结果未确认时联系管理员检查待核查记录，不反复上传。取得分享地址不等于下载授权；远程源当前不开放分享，不要要求助手根据文件名猜测私人地址。

### 10. 大文件分片续传、重启恢复与节点绑定

适用角色：成员、空间管理员。

启用独立 LOCAL 续传后，浏览器从8MiB开始选择分片上传，分片大小4MiB，单文件最多50MiB。中断后在同一账号、同一存储目录重新选择原文件，可根据摘要和收据上传缺失分片；会话有效期固定24小时。每账号最多3个未完成任务，声明暂存额度合计100MiB。远程 OSS/S3 当前使用普通代理上传，不提供这套分片续传。

续传绑定原内容节点，节点身份、空间或授权变化可能拒绝继续。切换到另一内容节点不能自动接管任务；未配置独立私有暂存目录时续传关闭，使用普通上传。最终完成状态未知时先刷新收据，不能把“正在合并”当成成功或反复创建同名文件。

### 11. 新建目录、重命名、复制与移动文件

适用角色：成员、空间管理员。

在当前授权目录使用新建目录或文件行操作。LOCAL 本地存储的重命名、复制和移动都要求对应操作权限，目标目录也要在可访问范围内；不允许用路径跳转、绝对磁盘路径或符号链接绕开个人目录。远程 OSS/S3 只开放列表、读取、上传和新建目录，新建目录还要求已保存的读写验证与 mkdir 授权；远程重命名、复制和移动尚未开放，界面会隐藏入口。

遇到同名冲突先刷新目录并选择新名称，不假设系统会自动覆盖。LOCAL 复制、移动或重命名涉及容量和目录状态核验，源或目标在操作期间变化时应重新确认。操作预览没有修改文件，只有完成的业务结果才能证明操作成功。

### 12. 文件预览支持格式与大小限制

适用角色：成员、空间管理员。

独立后端在线预览支持 PNG、JPEG、GIF、WebP、PDF 和 UTF-8 编码的 TXT、MD。图片和 PDF 最多20MiB，文本最多1MiB；格式不支持、编码不正确或文件过大时，下载后用本地软件查看。DOCX 可用于学习资料文字提取，不等于已支持在线 Word 版式预览。

预览使用当前登录和目录读取权限，私有文件不会交给外部文档预览网站。文件变化或授权撤销后需要重新读取，已有预览结果不代表仍有下载资格。

### 13. 搜索文件名与个人学习正文检索的区别

适用角色：成员、空间管理员。

云盘文件搜索使用当前账号和目录范围的文件目录索引，适合查找文件名；个人学习页检索的是主动归档资料中已经提取的文字，两者覆盖范围不同。没有归档到学习课程的文件，不应被描述成小芽已经读过正文。

文件索引有数量和目录范围上限，也可能需要刷新；找不到结果时确认存储源、授权路径、文件名称和索引状态。检索结果不是绕过下载权限的入口，删除、移动或撤权后仍要按当前源文件重新验证。

### 14. 回收站保留7天且仍占容量，如何恢复或彻底删除

适用角色：成员、空间管理员。

独立 LOCAL 文件删除进入受控回收站，保留期7天，每账号最多200条活动回收记录。回收站里的文件仍计入容量；删除后立即上传仍提示容量不足时，先检查回收站实际占用，需要释放空间时再明确彻底删除。到期清理是后台有界处理，不保证第7天整点立即释放。

恢复要求当前授权仍有效，且原目标路径没有冲突；原位置已有同名文件时先处理冲突，不自动覆盖。彻底删除不可恢复。状态不确定、授权改变或存储故障时，应先核对记录和文件状态，不反复点击来猜测结果。

### 15. 创建需要登录的单文件分享

适用角色：成员、空间管理员。

当前独立后端分享仅支持单个可读取的 LOCAL 文件，最大50MiB，不能分享整个文件夹；远程 OSS/S3 分享尚未开放。创建时明确选择“本工作空间”或“已加入的课程”；接收人必须登录，并符合对应空间或课程成员资格。不可猜测的分享 ID 只标识规则，不能代替登录，也不提供匿名外链或永久公开下载。

默认有效期7天，可设未来30天内的到期时间；每账号最多100个有效分享。需要对外合作时也应先确认对方能够按规则加入，不把链接地址本身当作授予整盘权限。

### 16. 分享过期、源文件变化或接收人无权限

适用角色：成员、空间管理员、全局管理员。

分享每次读取都检查有效期、撤销状态、分享者当前文件权限以及接收人当前空间或课程资格。源文件被替换、移动、删除或内容摘要变化时，原分享会失效，应让分享者核对后重新创建；它不是一份永久文件副本。

同空间分享不向其他空间开放；课程分享要求双方仍为相应课程成员。分享者可撤销自己的分享，全局管理员可治理撤销，但管理员角色不自动得到分享正文。分享失败时检查以上条件，不要求发送密码、Token 或服务器真实路径。

### 17. 建立个人课程并归档学习资料

适用角色：成员、空间管理员、全局管理员。

进入 /learning 创建个人课程，可填写课程名称和学期，再选择自己当前可读取的 LOCAL 文件归档。归档保存资料引用和本地提取的文字，不移动或复制云盘原文件。每个账号最多50门个人课程，每门最多200份资料。

个人课程属于本人账号，与 /courses 的共享课程不同。删除资料索引或个人课程只删除引用和索引，保留云盘原文件；把文件归档到个人课程也不会向同空间成员或管理员共享正文。

### 18. 课程资料支持TXT、MD、PDF、DOCX及文字覆盖范围

适用角色：成员、空间管理员、全局管理员。

个人学习资料本地提取支持 TXT、MD、PDF 和 DOCX，单份源文件最多10MiB。每份最多索引100000字符，PDF最多处理前100页；页面显示已覆盖字符、页数和截断信息，不能把有限覆盖说成已读完整份资料。

仅提取可用文字，不做图片 OCR；扫描版PDF、图片中的公式和图表可能没有可检索正文。加密或损坏文档可能被拒绝。DOCX 提取文字时不跟随外部链接，也不执行宏；无结果时先看资料是否确有可提取文字。

### 19. 资料内容变化后刷新索引或重新关联文件

适用角色：成员、空间管理员、全局管理员。

修改原文件内容后，在学习资料列表刷新索引，重新读取并替换旧的提取文字；移动或改名后，用重新关联选择新的可读文件。重新关联不替你移动云盘文件，也不能把别人的私人文件变成自己的资料。

检索命中前会重新读取源文件并核对内容摘要和当前权限，源内容变化、文件丢失或授权撤回时旧摘录被跳过。请根据页面提示刷新索引或恢复正确授权，不把“已归档”当成始终有权读取旧文本。

### 20. 让小芽依据个人课程资料回答并核对引用

适用角色：成员、空间管理员、全局管理员。

在 /learning 选定个人课程后提出具体问题；需要让模型使用私人资料时，按页面选择本轮允许使用私人上下文。此授权按轮次使用，不会因为上一轮允许就自动扩大到所有私人文件。只检索已归档且当前仍可读的资料片段，不自动遍历整个磁盘。

回答中的引用用于核对资料名称和文本片段，片段编号不等于PDF页码。无命中、已截断或部分源文件不可用时，不能宣称全部资料已经检查完毕。模型回答仍需与课程原文核对；本地索引和关键词检索不表示模型训练或语义向量检索。

### 21. 加入跨空间共享课程与读取课程资料

适用角色：成员、空间管理员。

共享课程位于 /courses，由空间管理员创建，普通成员或其他空间管理员可通过有效课程邀请码加入。加入课程不会改变你的工作空间归属，也不会取得创建者私人云盘的权限。课程邀请有有效期、人数和启用状态等规则，课程码与工作空间邀请码不可混用。

加入后在课程成员资格允许范围读取课程资料。退出、被移除、课程停用或账号不可用后，后续请求会重新拒绝读取；已知文件标识或曾经打开过页面都不能绕过当前课程资格。

### 22. 申请共享课程上传权限与课程容量

适用角色：成员、空间管理员。

课程成员读取资格与上传资格分别管理。需要贡献资料时向课程创建者申请上传，获批后可按授权持续上传；其他空间管理员作为课程成员时也不能自行批准自己的上传。创建者可拒绝或撤回上传资格。

课程文件在独立课程目录存储，与个人云盘额度分开管理。上传会检查单文件、课程、创建者和服务器总量预算；容量不足不能通过换一个请求接口绕过。共享课程文件不会自动成为个人学习索引，个人学习归档和共享课程上传是不同流程。

### 23. 小芽简洁回答、详细解释和来源核对

适用角色：成员、空间管理员、全局管理员。

小芽可结合项目帮助、审核发布的知识和本轮明确允许使用的个人资料回答。默认选择简洁；需要推导、步骤或例子时切换详细或在问题中明确要求。先说明目标、所在页面和错误提示，通常比只说“不能用”更容易得到可核对的帮助。

模型必须由管理员配置才能生成回答，未配置或暂不可用应明确报错，不能编造一段成功回答。助手的解释不等于文件操作结果；真正操作应查看预览、确认和最终执行记录，知识来源不足时应保留不确定性。

### 24. 附件分析与上传云盘的区别及附件大小

适用角色：成员、空间管理员、全局管理员。

把附件交给小芽分析，是在本轮解析可用文字作为回答依据，不代表已保存到云盘。希望保存文件时选择上传目标目录并查看上传结果；希望解读资料时选择分析。两种用途不能根据拖入文件这一动作互相推定。

独立附件分析支持 TXT、MD、PDF、DOCX，最多3个，单个2MiB，合计4MiB，并有提取文字预算。文件过大时先摘取相关章节或转为较小文字资料；不要附带密码、API密钥或不需要处理的个人资料。

### 25. 主动保存、编辑、停用或删除长期记忆

适用角色：成员、空间管理员、全局管理员。

长期记忆用于本人主动保存的稳定偏好或背景，例如希望回答简洁、正在学习的方向。记忆面板可新增、编辑、删除、清空和启停，每账号最多50条，每条最多500字符，只对本人开放。助手不会因开启记忆就自动保存全部聊天或文件。

停用后记录仍保留，但不应参与启用状态下的记忆使用；需要抹除时明确删除或清空。不要存放密码、验证码、Token 或API key。记忆是应用持久化记录，不是训练模型参数。

### 26. 让Agent整理文件前先检查预览并确认

适用角色：成员、空间管理员。

在已选定存储和目录后，可请求整理文件、按日期命名或批量导入个人学习资料。系统先生成可审核的步骤预览；逐项核对源路径、目标路径和课程等信息，明确确认后才创建执行任务。生成预览或模型说“已安排”都不表示文件已修改。

预览有有效期并绑定当前账号、空间和授权，过期或目录变化时重新生成。手动步骤支持受控的新建目录、重命名、复制、移动和索引资料，不能让模型任意运行服务器命令；目录或目标不明确时应先补全信息。

### 27. Agent任务状态、取消、失败与重试

适用角色：成员、空间管理员。

在 /agent-tasks 或助手任务卡片查看待确认、已提交、执行中和逐步结果。执行前后会核验账号、空间、目录权限和源文件状态；权限收回、同名冲突、源文件变化或服务故障都可能阻止执行。结果以任务记录为准，不能用聊天答复代替。

取消不保证撤销已经完成的步骤。失败后先检查每一步结果，再按页面允许的重试入口处理；不要连续提交多个同一任务来猜测是否成功。任务处理有幂等和执行凭据保护，但不承诺整批操作自动回滚。

### 28. 每周自动生成整理预览，仍需本人确认执行

适用角色：成员、空间管理员。

每周规则按 Asia/Shanghai 时区，在选择的星期和时间为指定存储目录生成整理、日期重命名或学习归档预览。每账号最多20条规则，可以启停，也可主动请求立即生成预览。规则保存不代表已经执行文件操作。

到时只生成待审核预览，不自动替用户确认，不自动执行文件变更。授权变化或服务故障可能使预览失败，查看规则状态和错误后处理；暂停规则会停止后续触发，但不会抹掉既有任务历史。

### 29. 回答没有解决问题时提交本轮反馈

适用角色：成员、空间管理员、全局管理员。

小芽回答未解决问题时，点击本轮反馈入口，只提交明确选中的完整问题和回答供全局管理员核验。反馈需对应后端已完成的回答记录，重复提交相同轮次按幂等处理，不会因此上传其他聊天或文件。

提交未解决不等于自动创建人工客服会话，也不会自动训练模型或发布知识。需要人工客服时使用明确的转人工入口。管理员会填写修正答案并审核，是否发布、发布范围与版本是后续单独处理。

### 30. 空间管理员审核成员、分配目录并重置成员密码

适用角色：空间管理员。

空间管理员在 /workspace-admin 处理本空间加入申请和普通成员管理。审核加入、启停账号与授予云盘目录是不同操作；通过加入申请后，仍需处理云盘申请，明确个人目录、上传权限和容量。不能替其他空间审批，也不能修改全局管理员。

重置密码只面向本空间普通成员，按页面要求核对新密码；重置后原会话失效。成员停用或撤权会影响后续文件与任务请求，不要把前端隐藏菜单当作已经完成后端权限管理。

### 31. 空间管理员申请本地云盘并审批成员容量

适用角色：空间管理员。

需要服务器本地空间时，空间管理员提交用途和期望容量，由全局管理员批准后分配受控目录。空间管理员不能在浏览器输入任意服务器绝对路径来创建本地云盘，也不能通过成员注册自动分配服务器磁盘。

获批后处理本空间成员的云盘使用申请，为每个成员分配独立根目录、额度和上传开关；不要把管理员根目录直接授权给所有人。对未知或统计失败的容量应先排查，不能把读取失败当成零使用量。

### 32. 课程创建者管理邀请、成员和上传资格

适用角色：空间管理员。

空间管理员可创建共享课程并管理自己创建的课程，设置名称、说明、容量和启用状态。邀请可按规则设置有效期和人数，必要时撤销；审核成员上传申请，按需撤回上传权限或移除成员。普通管理员作为别人课程的成员时仍受对方课程规则约束。

课程资料保存在独立课程空间，不应混入创建者个人目录。课程停用会影响后续资料读取；删除非空课程前需通过资料业务先处理文件和容量，不能只删数据库记录来假装释放磁盘。

### 33. 全局管理员配置独立本地存储及续传目录

适用角色：全局管理员。

全局管理员治理空间本地盘申请和受控存储连接。LOCAL 服务端须显式配置受控存储根；课程根与云盘根不得重叠。本地目录仍由空间管理员申请、全局管理员批准并维护，不能把服务器路径填进远程 Endpoint。当前另外实现 OSS/S3/MinIO 的列表、读取、新建目录和上传，普通管理员可在本空间添加；全局管理员添加时须选择已启用且存在普通管理员的工作空间。WebDAV、FTP、SFTP 尚未开放。

启用 LOCAL 续传还需独立私有暂存根 SC_UPLOAD_STAGING_ROOT，与受控根和课程根互不包含，且准备稳定 SC_CONTENT_NODE_ID 和节点独占持久化存储。保留同一节点身份才能恢复该节点任务，不支持跨节点自动接管。远程上传也需要私有暂存目录，另需凭据加密主密钥和端点策略；各项配置不应写进聊天。停用远程源不删除对象，当前保留远程连接历史。

### 34. 全局管理员审核、润色、发布与撤回知识

适用角色：全局管理员。

在 /admin/ai-feedback 查看明确提交的反馈，人工核对并保存修正答案、标记已解决后，再按当前版本发布。AI辅助润色只是草稿，仍需核验保存；错误原回答不自动入库。发布和撤回比较版本，页面过旧时重新读取，避免覆盖他人审核。

普通来源可按规则发布原空间知识；全站发布需要额外明确确认。可发布的课程来源只能回原课程，不能扩为全站或另一课程。含个人资料、附件、私有历史等来源的回答不能直接发布共享知识；人工改写不会清除来源限制。版本历史保留，检索只使用未撤销且未被替代的活动版本。

### 35. 全局文件业务统计与容量数字的含义

适用角色：全局管理员。

文件业务统计按受控业务记录汇总文件索引、回收站、分享、课程和上传等状态。配额上限、当前业务账本使用量、暂存预留与真实磁盘占用含义不同，不能把所有授权额度相加说成磁盘已经使用的容量。回收站未彻底清理仍占空间，续传暂存也有额外磁盘峰值。

统计依赖不可用、覆盖有限或未完成核验时，应显示未知或相应说明，不能补成零。统计用途不需要拉取成员私人文件正文、私人课程索引或完整问答，聚合视图不应成为跨账号读取入口。

### 36. WebDAV、FTP、SFTP尚未开放，OSS与S3已实现的范围

适用角色：成员、空间管理员、全局管理员。

独立后端已实现阿里云 OSS、S3 兼容存储和 MinIO 的远程 list、read、mkdir、upload，即列表、读取、新建目录和上传。上传为1字节至50MiB，读取上限50MiB；新建目录和上传要求已保存的读写验证及当前账号授权。文件内容经登录态代理传输，不向浏览器返回存储凭据或预签名存储 URL。

WebDAV、FTP、SFTP 尚未开放。OSS/S3 远程复制、移动、重命名、删除、回收站和分享尚未开放，不能把 LOCAL 的功能直接套用到远程源。旧页面出现某协议不等于已接入；不要改数据库引擎名或复用旧直传凭据绕过限制。已实现协议不等于已完成真实云账号验收，当前部署版本与管理员实际配置仍须核对。

### 37. 普通管理员连接阿里云OSS、S3或MinIO远程存储的步骤

适用角色：空间管理员、全局管理员。

普通管理员在本空间进入“添加存储源”，选择阿里云 OSS、S3 兼容存储或 MinIO；全局管理员须先选择已启用且存在普通管理员的工作空间。本地目录仍需申请，由全局管理员批准分配，不能用远程连接表单代替。先让运维准备私有 Bucket、专用身份与不重叠前缀，再填写名称、可选别名、API Endpoint、Bucket、Region、AK/SK、可选临时 Token、专用目录前缀和 Path Style。新建必须填写完整 AK/SK；不要把密钥发给助手。

API Endpoint 填 HTTPS API origin，不含账号、路径、查询或片段；Bucket 单独填写，Region 与实际地域一致，不填控制台或签名文件链接。OSS 可用地域 API 端点，MinIO 地址需运维加入精确端点白名单；Path Style 按提供方要求设置，表单 OSS 默认关闭、S3/MinIO 默认开启。前缀留空占整个 Bucket 范围，同一端点和 Bucket 下前缀不能相同或互相包含，不能含 ..、反斜杠或 .studentcloud- 保留目录。

检查填写后选择只读或读写测试，再保存。编辑凭据留空表示保留，配置已变化须重新读取。更换 Endpoint、Bucket、Region、Path Style 或前缀前先单独停用并保存；其他管理员分配的连接位置只能由创建者或全局管理员改。存在正在执行或待核查写入时不能修改连接。退役时停用并保留历史，停用不删除远端对象。

### 38. 远程只读测试连接、读写探针与保存后权限的区别

适用角色：空间管理员、全局管理员。

“检查填写”只校验表单，不访问远端。“只读测试连接”仅对所选前缀列目录，不写对象；通过只能说明这次列目录成功，不等于已验证读取、上传或删除权限，也不保存配置。要开放写入，勾选“同时验证写入、回读和清理测试文件”，测试会在专用前缀下的 .studentcloud-probes/<随机UUID> 条件创建随机内容，再次同名创建确认同名拒绝，随后回读比较并清理本次探针。

列目录、条件写入、同名拒绝、回读和清理必须全部通过；无法确认探针清理时测试失败，不要反复测试或批量删除保留目录。保存已启用连接时后端按当前选择再次测试；未勾选写入验证而保存会保持只读，只有读写验证通过并保存后才开放上传和新建目录。单独测试成功不会改变已保存配置。

编辑页的“已保存配置：只读 / 读写已验证”表示当前生效状态；勾选框或一次测试提示不能代替它。成员还需本空间管理员授予 upload 或 mkdir 与足够容量；连接读写已验证不会自动给所有成员写入权限。

### 39. OSS版本控制与S3不覆盖写入、探针清理失败的处理

适用角色：空间管理员、全局管理员。

远程写入只创建新名称：S3 使用 If-None-Match: *，OSS 使用禁止覆盖条件，不采用先 HEAD 再覆盖 PUT。遇到同名冲突先核对目录并选新名称；不能用关闭条件检查来绕过。S3 兼容服务须实际通过同名拒绝、回读和探针清理测试，标称兼容不能代替验证。OSS Bucket 版本控制为 Enabled 或 Suspended 时禁止写入，暂停版本控制不能绕过；每次 OSS 条件写入重新检查，状态不明也拒绝。只读连接不因此获得写入能力。

为专用 Bucket 或前缀配置最小权限：列目录与容量扫描需要 Bucket 级 List 权限，读取需 GetObject，新建目录和上传需 PutObject，版本状态核验需 GetBucketVersioning。DeleteObject 只需开放到专用前缀下 .studentcloud-probes/*，不需要开放用户文件删除；S3 探针带版本 ID 时，精确版本的 HEAD/清理还需对应 GetObjectVersion、DeleteObjectVersion 权限。

清理会核对探针身份、元数据、大小、ETag 和版本，只清理本次测试拥有的对象或其精确版本。清理结果未确认时保持测试失败，记录错误和测试对象交运维调查；不要重复测试、批量删除保留前缀，或让外部程序改写 .studentcloud- 目录、操作元数据或 Bucket 版本状态。

### 40. 成员远程云盘配额不足、访问审批和个人目录隐私

适用角色：成员、空间管理员。

成员通过“申请云盘 / 查看容量”（/cloud-access）选择本空间远程源并提交申请，由本空间普通管理员审批上传权限与个人容量。加入空间本身不授予远程云盘。每个远程源绑定一个工作空间，成员根固定为 /members/u<用户ID>，普通管理员根为 /admins/u<用户ID>，浏览器均显示自己的 /；实际对象在专用前缀加个人根之下。成员不能通过路径参数访问别人的目录，普通管理员自己的目录也不应直接授权给成员。全局管理员具备源的管理范围，不应代替成员身份日常访问。

遇到远程配额不足，先在 /cloud-access 核对该账号在该存储源的容量和授权，再联系空间管理员调整。上传还要求远程连接已完成读写验证并保存、upload 授权有效、账号和空间可用，单文件在1字节至50MiB；只读连接即使有容量也不能上传。系统写入前重新核对授权和配置版本，不因旧页面显示可用而放行。

列表/容量扫描每页最多1000项、最多20页、累计最多10000项并有时间预算；扫描超出预算会明确失败，不能把失败算成零占用。远程复制、移动、重命名、删除、回收站和分享尚未开放，不能靠远程回收站清理释放额度；需要数据处置由管理员与运维另外安排。写入结果未确认时请管理员检查待核查记录，不反复重传。

### 41. 管理员定位未确认写入：UNCERTAIN、PUBLISHING与手动核查

适用角色：空间管理员、全局管理员。

远程发布开始后超时或断网，写入可能已经发生。UNCERTAIN 表示结果待核查；持久记录若停留 PUBLISHING，也需核对，不能直接认定成功或失败。系统保留该源写入冻结，其他实例不会自动接管重放。不要重复上传同一文件。由全局管理员或该空间普通管理员打开已保存远程源编辑页，展开“待核查写入”，点击“读取待核查写入”，按操作编号核对用户目录内路径、状态和时间，再点击“检查写入结果”。页面不自动轮询；检查使用已保存连接，不携带表单凭据，也不重新上传。

只有远端对象 key、大小、studentcloud-operation-id 与持久记录及配置版本精确一致，才返回 CONFIRMED，将记录改为 COMPLETED 并解除冻结。对象不存在、同大小但元数据缺失或不符、配置版本不符都保持 PENDING 和冻结；当前没看到对象不是未写入的证据。检查失败保留原状态，连接恢复后再次检查。PREPARING 表示准备中，不能据此认定远端已发布。

管理接口为 GET /admin/storage/{id}/pending-writes、POST /admin/storage/{id}/pending-writes/{operationId}/inspect，要求对应管理权限；列表只含操作编号、发起用户ID、用户目录内路径、状态和毫秒时间，不返回完整 Bucket key 或凭据。不要删 SQL guard、改操作编号、覆盖对象或反复上传来解冻；无法获得匹配证据须由运维人工调查，当前没有强制放行入口。

### 42. 全局管理员配置独立远程凭据主密钥、端点白名单和暂存目录

适用角色：全局管理员。

运维须向独立内容服务注入 SC_STORAGE_MASTER_KEY：32 个随机字节的标准 Base64 编码，由受控 Secret 管理，多实例使用同一值。数据库只保存 AES-GCM 加密凭据；备份数据库时另行保管对应主密钥。当前没有自动主密钥轮换迁移，直接更换或丢失会使已有凭据无法解密。远程上传还需已存在、可读写的私有绝对暂存目录 SC_UPLOAD_STAGING_ROOT，置于可浏览云盘目录之外。

默认官方端点使用 HTTPS；自建 MinIO 或非默认端点由 SC_STORAGE_ALLOWED_ENDPOINTS 放行精确 origin，协议、主机、端口必须相同，不支持通配符。Endpoint 不含账号、Bucket 路径、查询或片段；HTTP 只允许白名单内回环地址，远程或内网 IP 的 HTTP 不被接受，不要关闭 TLS 校验。浏览器经内容服务代理读写，不使用旧列桶/CORS 辅助接口，也不接收明文凭据或预签名存储 URL。

详情 AK/SK/Token 空白是设计行为，credentialsConfigured 表示已有加密凭据；编辑留空保留，更换 AK/SK 时填写完整一对。空 Token 也保留，当前不能靠空值清除。不要在聊天、Git、前端配置、日志或截图发送 AK、SK、Token、主密钥。当前协议测试使用合成凭据，尚未使用真实 OSS/S3 云账号完成验收，不表示已经部署；上线前在获准专用 Bucket/前缀核验隔离、容量、条件写入、回读与探针清理。

## 全局管理员整理未解决问题

1. 打开 AI 反馈列表，选择一条未解决问题，核对原问题、完整回答和来源范围。
2. 先独立核实正确做法，在修订答案中写出适用条件、步骤和限制，不能把原来的错误回答直接当作正确知识。
3. 如需 AI 润色，点击“AI 辅助润色”。此动作把问题和当前修订正文发送给已配置模型，先去除个人信息；它只返回草稿，不保存、不发布。
4. 对照事实检查草稿，再采用并保存整理结果。将反馈标记为已解决前需要有正确答案。
5. 选择知识适用范围，核对空间/课程来源。全站发布需明确确认；课程知识只能留在原课程，含个人资料、附件或私有会话来源的反馈不能直接共享发布。
6. 发布后，新的提问可以召回当前生效版本。发现错误可以撤回；更新时保留历史，不让旧版本继续参与检索。
7. 多人同时处理时，服务核对版本和更新时间。遇到“已变化”应重新读取并合并修订，不反复提交旧内容。

## 课程资料整理建议

- 先按课程建立个人资料索引，再添加清晰的文件名和标签。知识检索会同时考虑文件名、标签、标题和正文。
- TXT、Markdown、PDF、DOCX 走本地有界解析；扫描图片没有 OCR。单份索引资料不超过10MiB，最多提取100000字符、PDF最多100页。
- 同一资料修改后刷新索引，路径变更后重新关联；直接把过期文字返回给模型会造成错误，所以检索会校验源摘要和当前权限。
- 本次关键词检索最多考虑200份索引资料，查询最多2000字符、最多32个检索词，每次新鲜读取预算50MiB。结果按相关性排序，不保证遍历全部资料。
- 项目帮助和审核知识的关键词检索不是向量语义检索。中文使用词组与双字片段，英文使用词边界；复杂同义问题仍可能漏召回。

## 回答、来源与执行结果怎样核对

- “项目知识依据”是网站用法和管理员审核内容；“资料依据”才是本轮课程材料片段，二者分别显示。
- 引用包含课程、资料及片段标识；有跳过或截断时显示覆盖提醒。无来源时不能据此认为文件不存在或所有材料都已检查。
- 简洁模式先给结论和必要步骤；详细模式补充适用条件、预期结果和失败处理。它们使用不同指令，而非只改变输出长度。
- Agent 预览表示尚未执行；执行中、已完成、部分完成、中断需要核查应按任务实际状态区分。遇到不确定结果先查文件和任务，不重复提交写操作。
