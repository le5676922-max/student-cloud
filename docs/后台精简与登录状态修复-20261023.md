# 后台精简与登录状态修复

本轮保留原登录动画、灰白与深色主题以及后端权限规则，只调整后台信息层级和登录状态处理。未修改业务数据库，未推送或部署到服务器。

## 登录反馈

用户反馈“显示密码错误但仍然进入网站”。本地真实 Vue / Element Plus 组件测试复现了一条误报路径：认证已经成功并保存凭据，随后页面导航异常，被原来的同一个异常处理分支显示成“登录失败，请检查账号密码”。这说明存在该缺陷，不代表已取得用户当时的网络记录并确定唯一原因。

- 认证错误仍显示服务端错误，不保存新凭据、不进入业务页面。
- 已认证后的导航异常单独提示“已登录，但页面未能打开”，提供“重新进入”。重试只导航，不再次提交密码。
- 成功后锁定重复登录提交、清空输入框中的密码，不把密码保存到记住账号配置。
- 识别 Vue Router 返回的中止结果，允许合法的业务路由重定向和重复导航。
- 守卫将目标重新定向回认证页时，恢复可提交表单，并提示登录状态未能确认，避免卡在“正在进入”。不绕过守卫，也不擅自认定密码错误。
- 离开页面或切换登录入口后，忽略旧请求或旧导航的迟到异常。
- 文件夹密码错误明确标注为“文件夹访问密码”，提示它不是登录密码；文件夹密码校验、授权和缓存规则不变。

## 管理界面

- 导航默认保留四个常用入口：总览、工作空间、空间人员、存储源。其他功能放在“更多管理”下的分享与链接、站点设置、日志诊断分组中。
- 当前页面所在分组自动展开；其余可折叠。支持 Esc 收起、焦点恢复，折叠区域不会继续接受键盘焦点。
- 原管理路由、日志下载、退出登录与访问权限保留，不是删除后台业务能力。
- 总览首先展示四个核心指标和运营提醒。日志与运行诊断、工作空间明细默认折叠，展开不重新请求数据；异常与未知数据提示不被折叠隐藏。
- 站点设置默认展示站点名、根路径名称、备案号和同时上传数；品牌外观、连接与兼容按需展开。折叠不卸载表单字段、不丢草稿，保存校验失败会展开对应区域并定位字段。

```powershell

pnpm typecheck
pnpm build
```

- 全量前端测试：591 项通过，0 失败、0 跳过。
- 类型检查和生产构建通过；本轮修改的 Vue / JS 文件 ESLint 检查通过。
- 新增或扩展真实组件、Element Plus 表单、内存路由和异步乱序回归。请求、凭据均为隔离测试桩，不使用真实用户密码，不调用外部模型或发信服务。

本轮没有浏览器视觉验收或用户真实会话复测，也不将自动化测试等同于生产环境完整验收。如果仍出现提示，需要记录完整提示文字、失败接口及响应码，以区分登录、文件夹验证和网络故障。
