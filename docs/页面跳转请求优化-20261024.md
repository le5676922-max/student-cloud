# 页面跳转请求优化

本次针对能从代码复现的重复请求和取消失效修复，不改变页面权限边界，不缓存已完成的登录授权。

## 修正内容

1. 云盘页头不再在路由守卫验证后另发一次登录检查。页头直接使用本次路由检查写入的身份，避免重复访问数据库，也避免迟到的旧身份覆盖新会话。
2. 快速点击多个私有页面时，仅复用同一凭据、同一后端地址下仍在进行中的登录检查。旧页面跳转立即取消，最后一次点击使用真实服务器返回的角色判定权限。请求结束后不缓存该授权结果，后续正常跳转仍重新检查；切到登录页、切换凭据或超时会取消旧请求。浏览器无法读取凭据时，也立即取消旧请求并返回登录页，避免它继续占用连接直到超时。
3. 修复云盘列表 API 把 `signal`、`timeout` 当作查询参数的问题。取消信号和 10 秒超时现在传给真正的 HTTP 请求，离开旧目录可中止已无用的请求。小芽读取云盘列表也获得默认超时，不再无限等待。
