# 知识库、Agent 与回答质量实施计划

用户要求：完成文件业务后，详细完善“项目使用说明＋课程资料”知识库，再优化 Agent 和 AI 回答格式。沿用独立的三个业务服务与 Gateway，不更换前端主题，不修改线上环境。

## 目标与边界

1. 项目说明有可维护的版本、主题、角色范围和正文，覆盖真实已实现能力；检索可以找到中文自然提问中的关键知识。
2. 课程资料按相关性选取片段，保留所有权、成员资格、文件摘要与权限复核；明确显示未检索、跳过和截断情况。
3. “没有解决”反馈经过管理员修订、AI 整理、人工审核、版本发布和撤回形成闭环；不将错误旧答案静默当作正确材料。
4. Agent 将自然语言映射到已有安全工具，参数不全时澄清，写操作只生成预览并要求确认；不把文字回答当执行成功。
5. 简洁模式先回答问题，再给必要步骤；详细模式解释前提和操作；引用与执行结果分开，不输出思维链或虚构完成状态。

这是检索增强和产品质量优化，不是付费微调或训练模型参数。不擅自向外部模型发送课程文件；原有每轮私有资料授权继续生效。

## 工作项

### A. 项目知识与审核知识检索

- 为独立后端撰写项目帮助，至少包括账号注册、角色边界、空间加入、存储审批、容量与个人目录、续传、回收站、受控分享、个人资料、共享课程、课程上传审批、Agent 确认、反馈及故障处理。
- 使用有界中文词组/英文词汇和标题权重检索；排序稳定；不扩大课程与空间可见范围。
- 修复对话允许2000字符、知识检索仅200字符的不一致；超出检索预算时裁剪查询，不能让正常对话直接失败。
- 测试自然语言命中、无关问题不命中、角色过滤、撤回知识不返回和空间隔离。

### B. 课程片段质量

- 在现有读取数量和字节预算内，按标题、标签与正文相关性排序；抽取与提问相关的片段，而不是始终返回文档开头。
- 保留源摘要、新鲜授权及用户主动同意；不递归扫描整个私有盘。
- 引用包含课程标识、资料标识和片段；显示跳过/截断提醒，不声称穷尽全部课程材料。
- 测试较旧高相关资料优先、中文提问、文件变化与撤权仍被排除。

### C. 反馈整理闭环

- AI整理必须接收管理员填写的修订正文和来源版本/时间；空白修订拒绝，旧版本拒绝。
- 模型调用前后复核管理员权限和反馈版本，不自动保存、发布或覆盖他人修订。
- 前端清楚标记草稿、待审核和已发布；保留撤回及历史。

### D. Agent 与回复格式

- 将现有整理、按日期重命名等意图从正则散落判断集中为受限路由；缺少云盘或路径时给出具体澄清，批量写入仍需确认。
- 回答分别展示结论、必要步骤、来源与执行状态；代码使用代码块，常规简答避免大标题和冗长套话。
- 简洁/详细模式使用不同明确指令，不能只修改 token 上限；前端保持安全 Markdown 渲染。
- 测试长提问、两种格式、仅预览不执行、不支持操作不伪造工具、引用不丢失及上下文变化拒绝旧结果。

### E. 记录与验收

- 新增定向测试并运行依赖边界构建；通过 Gateway 使用临时 MySQL 与本机合成模型验收，不调用付费接口。
- 记录知识条目覆盖、检索预算、人工审核步骤及当前限制，更新过时的“尚未实现”说明。
- 不以合成模型结果宣称真实模型质量或外部 SMTP、向量服务已验收。
