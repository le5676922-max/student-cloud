# OSS / S3 远程存储接入实施计划

用户已确认直接接通阿里云OSS与S3兼容存储的添加、读写和权限流程；完成后继续优化业务。沿用三个业务服务+Gateway，保留界面主题，不部署线上，不修改旧后端、不复制ZFile运行代码。

## 参考与实施边界

本地完整源码按REA技能的源码场景追踪；源码是本地改造4.5.0，无法声称等同某上游commit。原逻辑与独立设计见《ZFile远程存储业务分析与独立接入设计-2026-10-27》。官方接口补证以OSS PutObject和S3条件写为准。

首批开放目录、读取、创建目录、50MiB内不覆盖上传以及明确的工作空间/成员授权。未经过原子语义验证的移动、删除、远程回收和公开直链不能伪装可用。已有LOCAL功能完整保留。兼容服务需通过真实条件写探针，不能仅凭类型标签认定安全。

## 已固定契约

- `cloud-drive` 新增JDK端口 `drive.object.ObjectStore` / `ObjectStoreFactory`。连接配置toString脱敏；提供分页list/head/read/requireCreateOnly/createOnly/cleanupProbe。
- SDK只在新适配模块 `cloud-object-storage`；Aliyun稳定SDK3.18.5，S3 SDK按官方已验证版本选择，均有界超时、无自动写重试、无CORS修改，读流关闭必须释放客户端。
- `cloud-drive-application.DriveOperations` 是授权后文件用例端口；现有MountService实现LOCAL。组合路由按数据库engine分发，HTTP保留原路径。
- 内容服务拥有加密远程配置、挂载记录、连接探针、前缀隔离和持久写状态；平台只提供账号/空间管理员元数据，智能服务不持有存储凭据。
- AES-GCM凭据主密钥由配置提供，数据库和前端不保存/回显明文；编辑空密钥保留原值，不能用掩码覆盖真实密钥。
- 默认HTTPS及受信提供商端点；自建S3端点需显式运维允许列表，禁止任意内网/元数据出站与重定向。
- 全局管理员分配空间时，为本空间普通管理员建立独立个人根；成员访问仍由普通管理员审批、限定容量和目录。跨空间拒绝。
- 远端网络不持SQL事务；写入采用短事务登记和持久状态，不靠进程锁保证多实例安全；不确定结果不自动重放。
- 连接测试只读与写入分开。写探针为系统私有前缀内的随机对象，校验原子不覆盖、读回内容与清理；清理失败独立报告，不能误报成功。
- OSS版本桶使x-oss-forbid-overwrite无效，写能力必须核验并明确限制；兼容S3条件头被忽略时禁止发布写配置。

## 验收

1. 修复并回归LOCAL添加中的别名参数、初始停用、历史申请删除冲突、锁顺序和旧账号异步响应问题。
2. 驱动协议测试覆盖签名/分页/条件写冲突/超时/关闭/探针清理，不发送真实AK/SK。
3. 配置测试覆盖端点限制、密钥加密与掩码、旧配置失败保留、空间管理员开通及跨空间拒绝。
4. 网关联调覆盖远程保存、管理员/成员目录隔离、额度、上传下载字节一致性、同名拒绝、撤权与未登录拒绝。
5. 使用临时MySQL和本机协议服务/兼容S3容器；真实阿里云联调需要用户提供配置，未执行则明确记录，不能声称已验收真实云账号。
6. 完成后优化审批可见性、未知/失败/待核查状态、容量反馈和操作提示，不改无关主题或旧网站。
