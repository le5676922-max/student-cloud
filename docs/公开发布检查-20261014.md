## 修复的发布问题

`frontend/Dockerfile.deploy` 现在在 `pnpm install --frozen-lockfile` 之前同时复制 `package.json`、`pnpm-lock.yaml` 和 `pnpm-workspace.yaml`。冻结锁所依赖的 overrides / allowBuilds 配置进入构建阶段，避免只复制锁文件导致配置不一致。部署契约测试验证复制顺序。

## 仍需部署者验证

1. 在有 Docker Engine 的服务器完成镜像构建、容器健康、`nginx -t` 和部署冒烟。
2. 按自己的账号验证 SMTP、模型、embedding、对象存储和 OCR；不能把模拟服务测试当成外部服务验收。
3. 使用独立数据做负载与磁盘测试。当前生产保持单后端，Redis 不等于多实例会话和任务已实现。
4. GitHub Actions 的实时结果以仓库 Actions 页面为准。本文不预先宣称新提交的远端工作流通过。
