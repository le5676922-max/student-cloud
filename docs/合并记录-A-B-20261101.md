## 冲突处理原则与结果

| 交叉点 | 最终保留的行为 |
| --- | --- |
| 本地云盘装配 | 同时注入上传限制、文件目录和可选容量账本；账本默认关闭，不强制改变旧环境行为 |
| 分片上传装配 | 保留真实账号校验、独立暂存目录、节点绑定和动态本地限制 |
| 本地上传 | LOCAL 分片最高 1 GiB，4 MiB/块，最多 256 块；服务端可调低；普通 multipart 和 OSS/S3 保持 50 MiB |
| 暂存与永久容量 | 按最坏 4 倍峰值预留暂存，最终账本只结算实际发布字节；旧会话也按保守峰值计算 |
| 续传与清理 | 活跃资源数量不包含已释放的历史回执；保留个人创建频次限制、撤权后本人取消及未知发布状态的预算 |
| 知识反馈导出 | 仅当前有效、已发布 GLOBAL 且通过公开来源校验的条目可导出；私有上下文不因人工改写而洗成公开样本 |
| 长期记忆 | 保留本人隔离、外部上下文明确选择及相关性过滤；编辑和单条删除强制传已读版本，防止旧窗口覆盖 |
| 帮助与评测 | 合并 48 条产品帮助，区分 LOCAL 与远程限制；同步知识版本与评测样例，保留角色过滤和未实现能力说明 |

另外修复了一处不会显示 Git 冲突标记的接口兼容问题：
`JournaledDriveOperations` 必须转发 `maxTransferBytes` 和 `uploadDiskAdmission`。
否则启用操作记录的装配会错误回退到 50 MiB，并跳过驱动的磁盘准入检查。
新增测试先复现该问题，再验证修复，覆盖功能开关开启和关闭两种情况。
