# RAG 与 Agent 自动化使用说明

2026-10-10 补充：本文保留前期实现记录；最新的工作台简化、目录快捷操作和存储源识别见[功能简化与智能存储配置说明](功能简化与智能存储配置说明.md)。长文索引覆盖、定时预览有限重试及最终回归见[业务优化实现与回归说明](业务优化实现与回归说明-20261010.md)。本文早期的测试与环境状态不代表当前运行状态。

适用范围：当前开发代码包含至 V70 的数据库迁移。本文描述已实现的功能及明确限制，不表示真实数据库已升级或已经部署到服务器。

## 1. 本次补充的业务能力

| 能力 | 入口 | 实际行为 |
| --- | --- | --- |
| 项目帮助 RAG | 小芽聊天 | 按当前角色检索项目功能、操作方法和故障说明，展示实际召回的条目与来源 |
| 私人课程资料检索 | `/learning`、小芽 | 检索本人已索引资料，并重新检查源文件权限和内容指纹，返回真实文本片段 |
| 文件分类整理 | `/agent-tasks`、小芽任务卡片 | 将当前本地目录中的文件移动到文档、图片、视频、音频、压缩包、代码或其他子目录 |
| 批量课程归档 | `/agent-tasks`、小芽任务卡片 | 为当前本地目录中符合条件的文件建立本人课程索引；不移动、不复制原文件 |
| 任务记录 | `/agent-tasks` | 最近 30 条本人任务，以及每一步的成功、失败、未执行状态 |

访客不能创建、查看或执行任务。系统管理员也不能通过任务 ID 查看其他用户的私人任务。管理员仍可通过已有账号管理功能撤销用户权限，但这不会赋予其私人资料检索权限。

## 2. 不配置模型也能使用自动化

1. 登录系统管理员或普通用户账号。
2. 打开 `/agent-tasks`；也可从课程资料库的“批量归档与自动整理”或小芽顶部的任务图标进入。
3. 选择本地存储源，填写相对于当前用户授权根目录的路径，例如 `/学习资料`，不是服务器的绝对路径。
4. 选择“按文件类型分类整理”或“批量归档到课程”。后者需要先在 `/learning` 创建本人的课程，再选择课程及标签。
5. 点击“生成任务预览”。此时只写入待确认任务记录，不会移动文件或建立课程索引。
6. 检查每个源文件、目标路径或课程编号；不符合预期时取消任务。
7. 点击卡片上的“确认执行”，再次确认弹窗。服务端领取任务后交给有界后台队列，页面自动刷新逐项结果；关闭页面不会取消已确认任务。

预览在创建后 10 分钟内有效。执行接口只接收任务 ID 和明确确认，不接受客户端替换步骤、路径或所属用户。

文件整理需要该存储源的 `move` 和 `newFolder` 权限；归档需要 `preview` 或 `download` 权限。受隐藏、禁止访问、禁止下载或目录密码保护的文件不能通过该流程绕过保护。

## 3. 通过小芽生成任务

自然语言聊天仍需要管理员配置的模型服务和有效密钥。以下示例中的存储源、路径和课程必须替换为自己的实际数据：

- “列出我的课程，帮我把本地存储源 `study` 的 `/数据库资料` 批量归档到数据库课程。”
- “帮我按文件类型整理存储源 `study` 的 `/待整理`，先给我看方案。”
- “课程资料修改后为什么检索不到？应该如何重新索引？”

新增工具为 `list_learning_courses`、`search_project_knowledge`、`plan_file_organization`、`plan_learning_import`。模型只能够查询和生成预览，没有确认执行、删除、覆盖或修改权限工具。即使聊天文字说“直接执行”，仍需要用户点击真实任务卡片确认。

生成任务后直接返回服务端保存的任务卡片，不再等待一次模型总结请求，减少不必要的等待和模型调用。一轮对话最多执行 12 次工具调用，工具轮数仍由已有配置控制。小芽使用真实流式输出，可点击“停止生成”；模型必须支持兼容的流式工具协议。生成中的文字不代表最终业务结果，任务和引用以完成后的真实卡片为准。

默认整轮生成／工具预算 90 秒，与单次模型请求超时区分；附件上传和解析在此预算之外，前端另有总等待保护。取消会关闭当前上游模型连接，但不能保证立即中断所有本地文件读取或解析。默认单实例最多同时处理 8 轮、每账号最多 2 轮。参数及反向代理配置见 [业务响应优化说明](业务响应优化说明.md)。

## 4. 任务状态与失败处理

| 状态 | 含义与处理 |
| --- | --- |
| `PENDING` | 待确认；可确认或取消 |
| `EXPIRED` | 尚未执行且超过 10 分钟；重新生成预览 |
| `CANCELLED` | 已取消，不会执行 |
| `RUNNING` | 已领取，正在排队或执行；页面自动刷新，不应创建重复任务 |
| `INTERRUPTED` | 重启或结果检查点异常后状态不确定；先核实文件和索引，不自动重放 |
| `SUCCEEDED` | 所有计划步骤均已完成 |
| `PARTIAL` | 一部分已完成，随后失败；剩余步骤未执行 |
| `FAILED` | 没有步骤完成；查看失败原因，解决后重新预览 |

数据库以条件更新领取任务，重复点击、刷新或同时提交同一任务不会重复执行。每一步之前重新检查账号状态、当前存储授权和文件状态；大小、修改时间、文件位置和文件身份与预览不一致时拒绝执行。这里的移动前校验不是全文哈希比较；课程检索仍使用完整内容指纹检查。

执行遇到第一处失败即停止，不会回滚已经成功移动的文件或建立的索引。同名目标文件不会被覆盖；生成预览时已存在的同名目标会被排除，确认前新出现的同名目标会导致该步失败。页面只展示本次实际纳入的步骤，不应将预览数量当成目录文件总数。

**超时或进程中断：**确认接口只负责领取和提交任务，不再等待全部文件操作；其前端请求超时为 15 秒，任务状态约每 1.5 秒刷新一次，连续失败时退避并提示手动刷新。客户端超时不等于服务端停止，请刷新同一任务。默认 2 个执行线程、最多 16 个排队任务；队列满时拒绝此次确认，任务仍待确认。运行中的任务不可通过取消待确认接口中止。

后端在文件写入后、记录结果前崩溃时，结果可能不完整；下一次启动将遗留 `RUNNING` 标为 `INTERRUPTED`，绝不自动重放。需要先核实文件和索引现状，再生成新的预览。这是单实例内存工作队列和持久化任务记录，不是持久化消息队列、断点续跑或多实例调度器；禁止多个后端实例共享任务数据库运行此版本。

## 5. 范围与容量限制

- 文件整理、按日期重命名和课程批量归档三种自动化均只支持本地存储；不支持 S3、WebDAV、OneDrive 等远程驱动的自动写入。
- 每次只扫描当前目录最多 400 个目录项，最多纳入 20 份文件，不递归子目录。超过扫描范围的文件可能不会出现在本次预览中；建议按目录分批处理。
- 分类整理只移动文件，不整理子目录，不删除、不覆盖、不自动分享，也不修改权限。
- 批量归档支持 TXT、MD、PDF、DOCX，每份不超过 5 MB；跳过同课程已索引的同一路径。
- 课程资料库仍限制每用户最多 30 份资料、50 门课程；新版持久索引每份最多提取 240,000 个 UTF-16 字符、PDF 最多处理 300 页，并显示实际覆盖范围。不提供扫描件 OCR；达到文字上限时末页可能部分覆盖，旧索引需要主动重新索引。聊天附件仍使用原 12,000 字符/30 页限制。达到资料容量或解析失败时任务会停止；预览并不保证每份文件一定解析成功。
- 每用户最多保留 20 个未过期的待确认任务。历史查询最多返回 30 条，并非自动删除旧任务；本版没有后台历史清理策略。
- 整理后文件路径改变，旧课程索引不会自动跟随，需要删除失效索引并按新路径重新添加。删除课程索引不删除源文件。
- 用户删除事件会清理其任务记录，不会由此删除源文件。

## 6. 两类 RAG 数据不要混淆

### 项目帮助知识

当前普通用户知识 67 条、管理员知识 98 条，共 165 条角色定向条目（有共同主题，不是 165 个互不重复功能）。包含课程资料、Agent 操作、安全边界和知识维护等内容。

检索采用本地关键词、中文片段和业务同义词打分，默认最多召回 4 条、最低相关性分数 20，初始上下文上限 5,000 字符。改善了长中文查询被单字误匹配的问题。它是检索增强生成，不是向量数据库或模型微调；召回测试通过也不保证所有自然语言问题都命中。

聊天中的“项目知识依据”来自后端实际检索记录，而不是从模型回答里猜测引用。标识为 `[K:条目ID]`。模型文字是否准确概括依据仍需要核对，不能把引用卡片当作答案必然正确的保证。

### 私人课程资料

资料来自当前账号已归档的真实文件，引用格式为 `[M资料ID-S片段号]`。片段号不是 PDF 原始页码。没有匹配、权限撤销或源文件变化的内容不能作为有效检索结果返回；需要时在资料库重新索引。

只有传给模型的本轮相关片段和附件内容参与回答，不会自动把整个云盘发给模型。但相关片段、当前问题、工具结果和附件内容会发送给管理员配置的 AI 服务。不要将没有授权发送给该服务的敏感资料用于模型对话。手动任务页面不调用模型。

## 7. 维护知识库

维护入口是以下两个 JSON 文件，不要只改生成的运行时文件：

- `backend/scripts/rag/user-site-knowledge.json`
- `backend/scripts/rag/admin-site-knowledge.json`

每条记录包含唯一 `id`、`title`、`content`、`source`、`tags`，内容须与真实业务能力一致。然后在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\backend\scripts\build-site-knowledge.ps1
```

将输入 JSON 和生成的 `backend/src/main/resources/ai/knowledge/*-knowledge.json` 一起提交。重新构建、重启后加载新知识；这不是在线编辑/热加载服务。`ProjectKnowledgeTest` 会检查源文件与运行时文件是否一致、角色隔离、常见问题召回及无关问题拒答检索。

可通过 `tongligong-student-cloud.ai.rag` 下的 `enabled`、`admin-location`、`user-location`、`top-k`、`min-score`、`max-context-chars` 配置调整知识位置及召回参数。降低阈值可能增加无关命中，不建议仅为“多返回内容”而降低它。

## 8. 数据库升级与 Redis

`V62__agent_tasks.sql` 创建任务表；`V63__agent_schedules.sql` 创建每周规则表，SQLite 和 MySQL 均有对应迁移。升级前备份原数据库和上传文件，用 Flyway 正常升级；不要重建业务数据库、删除历史迁移或手工伪造版本记录。

新增 V69 索引覆盖信息、V70 定时预览认领与有限重试。临时连接故障最多在 1 分钟、5 分钟后补偿生成同一次触发的预览，不自动执行文件操作；未知结果需核实后手动恢复。CAS 认领防止重复生成预览不等于整个应用已经支持多实例部署，原有执行队列、连接上下文和进程内缓存限制仍需遵守。

本次不引入 Redis：任务持久化和同一任务的原子领取由数据库完成，项目帮助知识在进程内读取，课程检索的指纹复用只限单次请求。Redis 不能替代文件权限重校验，也不能直接消除外部模型延迟。项目其他缓存还存在进程内状态，所以不能据此宣称已经支持多实例自动化部署。相关性能改动见 [响应性能优化与 Redis 评估](响应性能优化与Redis评估.md)。

## 9. 测试与复验

2026-09-28 本机复测：后端 138 项测试中 135 项通过、3 项按配置跳过；前端 43 项单元测试、类型检查和生产构建通过。生产构建有大资源块提示，但没有构建错误。完整范围及未覆盖项见 [项目测试报告](../项目测试报告.md)。

后端自动化测试使用临时 SQLite 数据库、合成文件和本地模拟模型服务，不使用用户业务库或付费模型。MySQL 回归沿用 CI 的隔离数据库任务；未运行 CI 时不能把脚本存在当成 MySQL 实测通过。

覆盖内容包括：任务只预览不执行、明确确认、过期取消、用户隔离、权限和授权根目录变化、同名保护、并发确认、批量索引、部分失败停止、异常信息脱敏、路径越界、待确认容量/步骤限制及项目知识召回一致性。

在后端目录执行：

```sh
mvn -B test
```

如需同时运行局部磁盘校验性能基准并打包，改用 `mvn -B -Dlearning.benchmark=true verify`。默认跳过该基准，避免将不同机器的耗时当成功能断言。

在前端目录执行：

```sh
pnpm run test:unit
pnpm run typecheck
pnpm run build
```

自动化接口测试不代替真实模型效果验收或浏览器人工操作验收。上线前应使用准备好的非重要样例文件，在实际部署环境核对预览、确认、刷新及权限边界；不要直接以重要目录作为首次整理对象。

## 10. 新增 Agent 操作

- 在小芽聊天框输入明确的“帮我上传文件”指令会打开本地文件选择；也可拖入文件。选择“存入云盘”后核对存储源和目录，再确认上传。上传前检查当前目录的同名文件，已发现的同名项默认跳过；失败文件可单独重试，重试时重新检查权限和同名项。并发上传仍需遵循目标存储源自身的同名处理规则，不能将前端检查视为原子无覆盖保证。
- `/agent-tasks` 可生成按修改日期（北京时间）重命名预览；需要当前账号的重命名权限。任务仍最多处理 20 个文件、只处理当前目录。失败的单个步骤可重新生成独立预览，已成功或完成状态不确定的步骤不会自动重放。
- 查重只读取当前账号有权限访问的本地目录，对同大小候选计算 SHA-256。单文件最多 20 MB、累计最多 100 MB、最多实际比对 60 个文件；受限项显示为跳过，不会自动删除。
- 每周规则在北京时间指定星期和时间自动生成待确认预览，可暂停或恢复。到点时会重新检查账号、目录和权限；规则不会在无人确认时直接移动、重命名或归档。查看最近任务即可找到生成的预览；上次触发异常展示在规则列表中。
- 小芽回答可在“简洁／详细”之间切换，默认为简洁。课程概览只使用本人最多 5 份已复核资料的开头片段，不代表整门课程所有资料，并保留引用。
