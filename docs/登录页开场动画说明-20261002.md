# 登录页开场动画

日期：2026-10-02。

当前状态：已按用户后续要求移除开场、转场和重播入口，登录页直接显示。下文仅保留此前实现的历史记录，不代表当前页面行为。角色互动与小芽不受影响。

## 历史实现（已移除）

从用户提供的视频中实际截取开头的眼睛、转动和白色标记三帧，在进入登录页时播放紫色开场，再淡出并显露现有登录界面。不是直接播放原视频，不包含音乐。

- 开场总长 2.4 秒，第 1.9 秒开始过渡到登录页。
- 当前标签页会话中只自动播放一次；登录页的“重播开场”按钮可再次播放。
- “跳过开场”和 Esc 键可立即进入登录页；开场期间 Tab 键不会进入被遮挡的表单。
- 登录表单在原位置保留，重播不会清空已填写内容，也不会重复初始化登录接口请求。
- 开场结束后解除表单的 `inert` / `aria-hidden`，必要时把焦点恢复到重播按钮或登录标题，不自动聚焦空输入框，避免产生无关的必填校验提示。
- 用户开启“减少动态效果”时不自动播放，并隐藏重播入口。标签页隐藏、图片加载失败或超时也会结束开场，不阻塞登录。
- 离开登录页时清理计时器与监听器，迟到的图片加载不会重新打开开场。

## 素材与代码

实际抽帧时间为视频的 1.0、1.6、2.0 秒。每张素材为 520 × 280 的 WebP，分别裁剪居中，使手机上也能完整看到主体。只截取中心插画，不带原视频界面文字、平台标识或音乐。三张素材总计 4528 字节，约 4.4 KiB。

| 文件 | 用途 |
| --- | --- |
| `frontend/src/assets/login-intro/opening-eyes.webp` | 开场眼睛 |
| `frontend/src/assets/login-intro/opening-turn.webp` | 转动眼睛 |
| `frontend/src/assets/login-intro/opening-mark.webp` | 白色标记 |
| `frontend/src/components/auth/LoginIntro.vue` | 独立开场组件与退出、焦点处理 |
| `frontend/src/utils/login-intro.mjs` | 有限时长的播放调度和安全会话标记 |
| `frontend/src/pages/login.vue` | 登录页接入和重播入口 |
| `frontend/src/styles/login.css` | 登录卡片显露过渡与重播按钮样式 |
| `frontend/tests/login-intro.test.mjs` | 开场边界条件单元测试 |

会话标记键为 `student-cloud:login-intro:seen:v1`，只保存是否看过开场，不保存账号、密码或令牌。浏览器不允许访问 sessionStorage 时直接跳过自动开场，仍可手动重播。

本次没有新增运行时依赖，没有修改后端、数据库、角色权限或小芽。原有邮箱 / 账号 ID 登录、验证码注册、安全登录入口仍沿用现有接口。
