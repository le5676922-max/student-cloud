# 本轮业务完善与验收清单

以下是用户逐项确认的范围，全部保留在本轮任务中。`[ ]` 表示尚未完成实现和验收，不能因为已有部分源码就报告为完成。用户已要求暂停部署：本轮只修改和测试本地项目，不更新服务器镜像、不切换正式域名。

## 云盘与存储权限

- [x] 普通管理员（TENANT_ADMIN）可以添加、管理本空间的第三方云盘；普通成员不能自行创建全空间存储连接。
- [x] 全局管理员（ADMIN）可以添加云盘，并查看所有普通管理员／工作空间的云盘，显示所属空间。
- [x] 普通管理员创建本地云盘必须先提交申请，由全局管理员审批。后端禁止通过改类型、复制、直接请求或注册时自动分配绕过审批。
- [x] 审批通过后分配受控服务器目录，不接受普通管理员任意指定服务器路径。
- [x] 云盘连接测试分别验证读取、可选写入、读回一致性与测试文件清理；随机独立测试文件不能覆盖或删除用户文件。
- [x] 不支持安全写测试的提供方明确显示能力边界；写入／清理失败不能报告完整成功。

## 成员、容量与隐私

- [x] 普通管理员只能重置本空间普通成员的密码；不能重置其他空间成员、普通管理员或全局管理员的密码。
- [x] 密码不回显，重置后旧会话失效，日志不保存密码。
- [x] 成员可以申请使用本空间云盘，所属普通管理员审批。
- [x] 普通管理员设置本空间成员的容量上限以及目录范围；不由全局管理员逐个设置成员权限。
- [x] 配额在后端上传、覆盖、复制、移动、分片上传及适用的直接上传流程中生效；并发不能绕过，不只做前端显示。
- [x] 个人目录默认隔离，课程共享另行授权；列表、搜索、预览、下载、分享和 AI 工具均执行当前访问权限。
- [x] 普通用户不能读取其他用户的邮箱、个人资料、密码散列、云盘凭据或私人文件；账号切换清除页面旧数据。

## 课程共享

- [x] 普通管理员可创建课程并导入资料。
- [x] 普通成员和普通管理员都能加入其他普通管理员创建的课程；课程身份与工作空间管理员身份分开判定。
- [x] 加入课程后可以读取该课程主动共享的资料，不获得创建者整个工作空间或个人云盘的访问权。
- [x] 上传使用**一次授权**：成员先申请，课程创建者批准后可持续上传；普通管理员加入别人的课程也不能自行授权。
- [x] 只有课程创建者可以处理本课程上传申请，权限撤销后立即停止后续上传。
- [x] 课程资料、配额、删除及索引范围都不能跨课程／个人目录越权。

## AI、人工客服与知识改进

- [x] 普通问题先由 AI 处理，首次“未解决”和单次网络失败不立即强推人工；明确请求人工始终可用，持续未解决才建议。
- [x] 点击未解决仍记录本轮反馈；不自动创建人工会话，不自动共享其他历史、附件和记忆。
- [x] 全局管理员查看反馈、人工填写正确答案，再可选 AI 润色；AI 结果可预览修订，不能把原错误回答当正确知识。
- [x] 管理员确认后批量写入可检索知识库，提供配套脚本；保留来源、版本和撤回能力。
- [x] 知识按空间／课程／全站范围隔离，私人课程问题不自动发布为全站知识。
- [x] 密钥不写入脚本、Git 或日志；真实模型调用和微调不伪称已完成测试。
