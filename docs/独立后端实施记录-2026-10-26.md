# Student Cloud 独立后端实施记录

> 本文记录本日早期的单进程/H2阶段。后续已按用户要求拆为 Spring Cloud 微服务并完成隔离 MySQL 联调，最新结果见 [Spring Cloud 实施记录](Spring-Cloud微服务实施记录-2026-10-26.md)。

日期：2026-10-26 · 开发版本：`0.1.0-SNAPSHOT`

本轮继续实施 [独立架构重写计划](后端独立架构重写计划书.md)。新工程位于 [backend-independent](../backend-independent/README.md)，使用自己的 Maven 模块、`io.studentcloud` 包、数据库配置与迁移，不依赖旧后端的构建产物或业务实现。整个产品仍处于迁移阶段，尚不能替换当前网站。

## 已完成的本轮增量

| 范围 | 本轮实现 |
| --- | --- |
| 容量与个人隔离 | 增长写入在数据库连接/授权行锁内核算真实目录用量；超容量拒绝，删除后容量释放；普通管理员和成员各自固定个人根目录 |
| 本地盘审批 | 普通管理员提交申请，全局管理员批准后在受控范围分配目录；不同 LOCAL 连接不得目录相同、互相包含或直接挂载受控总根目录 |
| 上传资源 | HTTP 层在 multipart 解析前限制两路上传；云盘上传私有暂存，网络读取不持有 SQL 事务，提交前复核权限和容量；暂存与可浏览目录隔离 |
| 未解决反馈 | 同一客户端消息幂等提交；异内容复用标识拒绝；全局管理员分页查看、保存修订答案和内部备注，旧版本修改返回冲突 |
| 审核知识 | 只有已整理的修订答案可发布；同时比较反馈版本和知识版本；支持历史、幂等重试与撤回；内部备注不返回成员或随问答导出 |
| 课程隐私 | 提交时验证课程资格；课程来源只能发布到原课程；检索前后复核成员资格；默认检索和通用问答导出不混入课程内容 |
| 人工客服 | 用户明确申请后持久化沟通；一次性 30 秒连接票据；实时通知不携带消息正文，读取正文仍需 HTTP 鉴权；注销后关闭连接 |
| 订阅就绪 | WebSocket 注册后先发 `support.ready`；前端重新读取快照，补上 101 握手与实际注册之间可能遗漏的变化 |

容量核算当前为有预算的真实文件遍历，并非常数时间账本。文件系统副作用不能随数据库回滚；服务器外部程序直接改文件也不参与锁。客服票据和通知通道目前是单 API 实例内存实现，跨实例通知需要后续接入共享基础设施。

## 前端变更范围

用户已允许必要的前端调整。本轮仅改动：

1. `frontend/src/pages/admin/ai-feedback.vue`：保存时携带服务端版本；根据能力字段展示“整理中”状态，兼容未提供新字段的旧后端。
2. `frontend/src/components/admin/AiKnowledgeCuration.vue`：发布携带反馈版本；独立后端未配置润色模型时如实提示，不显示操作成功。
3. `frontend/src/utils/support-realtime.mjs`：订阅就绪后补读一次，保留原有 `onopen` 行为以兼容旧服务。

未改登录主题、页面布局、角色形象与动画；未将现有前端代理切换到新后端。独立后端尚未配置模型润色，知识发布依靠人工核验，不代表模型微调或完整 Agent 自动化已经完成。

## 实际执行结果

| 检查 | 结果及边界 |
| --- | --- |
| Maven reactor | `-DskipTests package` 成功，9 个子模块均编译打包；未执行 Maven 测试套件 |
| 隔离启动 | 仅监听 `127.0.0.1:18193`，独立 H2 内存库；V1–V8 自有迁移全部执行成功，健康检查正常 |
| 账号流程 | 初始化、登录、空间管理员创建及成员创建走通；全局管理员调用普通管理员成员管理入口被拒绝 |
| 私有记忆 | 本人创建可读，另一空间账号不能看到该记忆 |
| 反馈与知识 | 分页、幂等提交、备注保存、旧版本冲突、禁止课程转全站、课程定向检索、离课拒绝、撤回停止检索通过 |
| 云盘容量 | 审批本地盘、成员申请授权、5 字节容量写满、额外写入拒绝、删除后重新写入及跨空间拒绝通过 |
| 客服与 WebSocket | HTTP 消息保存及读取、票据仅用一次、就绪信号、变更通知、其他账号隐藏会话及注销后以 1008 关闭连接通过 |
| 前端语法 | 两个 Vue 文件脚本/模板编译、实时工具语法及三个文件格式检查通过；未执行完整前端构建或浏览器全流程验收 |

初始脚本对课程最小容量和客服隐藏资源的 HTTP 状态预期有误，已按真实契约修正脚本。客服首通知检查暴露订阅注册时序问题，补充就绪屏障后上述隔离流程通过。检查使用合成资料、临时账号与随机内存密码；没有发送邮件、调用外部 AI 或连接旧数据库。检查结束后已停止临时实例。

这些结果仅适用于本轮执行的隔离 H2 基本流程。没有开展架构对照、压测、真实 MySQL、Linux 文件系统或双机运行验收，不能换算为吞吐量、延迟提升或生产就绪结论。
