# 业务修复与验收报告（2026-10-12）

本轮完成业务缺口修复及本地回归；**不等于生产环境已完成验收，也不等于所有存储协议和多实例功能已经支持**。未提交或推送 Git，保留工作区已有修改。

## 已实现

- 文件界面及 Agent 移动、重命名后同步操作账号本人的资料索引；同步结果不确定时明确中断，不重放已完成的文件操作。私人资料支持手工修复路径，重新校验权限与完整文件指纹。
- 可选外部 embedding 兼容接口、语义与关键词混合检索、模型签名隔离及失败降级。默认关闭，不复用聊天密钥、不自动上传旧资料；向量不经资料列表接口返回。
- 检索全程最多 2 个并发请求；SQL 在读取向量前限制账号、资料 ID、首查快照及每份 1 MiB 大小，单次向量读取最多 30 MiB。高维模型主动减少索引片段，页面说明实际覆盖。
- 可选本地 Tesseract OCR：仅文字层完全为空的 PDF，限制文件、页数、像素、时间、字符及并发。混合 PDF 不自动补识别图片文字。
- 本地代理上传断点续传：4 MiB 分片、单文件最多 2 GiB、24 小时有效期、完整校验、跨重启恢复和私有暂存配额。每步复核账号、授权、真实目录与目录密码。
- 续传暂存目录与新建、修改、复制、自动开通及旧初始化的本地云盘根隔离；清理公平轮询，不被前面的失败记录永久阻塞。Windows 空 `fileKey` 使用可信高精度创建时间，不能校验的文件系统仍拒绝。
- 最终发布排他创建目标，避免 Unix 普通重命名覆盖竞争文件。复制失败、关闭失败或回执失败保留 `COMPLETING`，不自动删除目标或重复提交。
- 邮箱找回密码、验证码用途隔离、单次消费、发送冷却与共享限流、SMTP 事务拆分；重置后旧凭据和会话失效，并检查登录并发竞态。
- 总览统计短缓存、Redis 共享限流及可信代理限制；缓存不用于授权。S3 家族原生快速分页，未知总数明确显示，当前页才签名，排序/全目录筛选回到完整模式。
- HTTPS WebDAV 安全只读预检、SFTP 可信主机指纹校验。目录密码不写日志；无效密码规则拒绝访问，不跳过保护。
- Docker/Nginx/MySQL/Redis 单后端方案、私有就绪检查、持久卷和资源限制。续传分片单独完整缓冲、大小和并发有界，普通上传及 SSE 仍流式转发。

## 上线前仍需验证

1. 本机 Docker CLI 可用，但 2026-10-12 仍无法连接 Linux Engine；尚未执行镜像构建、真实 Compose 启动或容器 `nginx -t`。服务器需按教程完成这些验收。
2. 独立 embedding 供应商尚未确定，未进行真实付费调用。API 地址、模型、维度和密钥配置须来自真正提供 embedding 的服务；DeepSeek 聊天模型不是向量模型。
3. 未提供隔离 Redis 服务，本机没有实跑 9 项真实 Redis 用例。已提供严格限定环回 16379 / DB15 的测试及 CI 作业；上线前须执行。
4. 未验证真实 S3/WebDAV/SFTP、真实 OCR 样本及阿里云负载。SFTP 原配置没有可信主机指纹时会拒绝连接，需要由可信渠道配置指纹。
5. Agent 写入仍为本地存储且需要确认；FTP/SFTP 独立连接预检仍不支持。登录会话、Agent 队列、目录票据等尚未完成多实例改造，生产保持一个后端。
6. 续传完成复制过程中目标可能短暂显示为部分文件；失败需核查后再决定是否另行上传。暂存配额不是工作空间容量配额，磁盘还须预留最终文件空间。

没有使用、保存或在报告中重复本轮聊天提供的新 API 密钥。建议替换曾发送到聊天中的密钥；真实凭据仅存放在服务器私有配置，不进入前端、镜像或 Git。
