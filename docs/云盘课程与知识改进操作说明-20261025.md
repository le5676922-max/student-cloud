# 云盘、成员、共享课程与知识改进

本轮只修改本地源码并进行隔离测试。服务器部署、镜像发布、正式域名切换仍暂停；已有 V4 镜像不包含本轮代码。运行新版后由 Flyway 执行 V76–V79，不能只更新前端。

## 管理云盘

空间管理员进入“工作空间管理 → 管理云盘”，可以新增和管理本空间的第三方存储。全局管理员的云盘列表显示所属空间，可管理所有空间的连接。

服务器本地云盘需要在云盘列表展开申请面板、填写用途，由全局管理员批准。批准后分配受控工作空间目录；空间管理员不能自行填写服务器绝对路径，也不能通过修改类型、复制、注册时自动分配绕过审批。已经批准的本地云盘可启停；路径和类型由全局管理员维护。

连接测试默认只验证读取。显式选择写入验证时，LOCAL 与 S3 使用随机独立小文件，依次验证写入、读回一致性和清理。测试不会覆盖已有文件；S3 版本桶按测试版本清理。读取、写入和清理分别报告。WebDAV 当前只有安全只读预检，FTP、SFTP 等不支持独立安全预检时明确提示；不把读取成功当作写入成功。

## 成员开通与隐私

加入工作空间、通过注册审核，并不自动获得管理员的云盘根目录。普通成员从账户菜单进入“申请云盘 / 查看容量”（`/cloud-access`），选择本空间云盘并提交申请。

对应空间管理员在“工作空间管理 → 云盘使用申请”审批，可以设置容量、允许上传与否。也可以在成员表中选定账号，进入权限抽屉调整目录和操作权限。全局管理员不代替空间管理员逐个分配成员权限。

个人根目录以稳定账号内部 ID 生成，例如 `/members/u21`，可进一步限制到其子目录。其他成员不会得到该目录授权。旧版成员根目录如果不符合个人隔离规则，V77 会停用其授权，文件保留原处；由空间管理员核实后重新授权，不自动搬移或删除旧文件。

容量按**成员在每个存储源上的授权**分别计算，界面单位 GB，后端保存字节数。0 表示不允许新增文件。上传、覆盖、复制、移动、重命名、分片完成都经过后端入口；受限成员获取应用内代理上传地址，不能借用直传凭据跳过校验。并发写入通过数据库授权行串行校验。

当前可准确测量 LOCAL 与支持原生分页的 S3 目录。目录统计最多 10,000 个项目、15 秒；超过边界或无法准确统计时拒绝写入并提示，避免把未知用量当零。不支持准确计量的其他提供方暂不开放成员受限写入，空间管理员可处理。覆盖与复制采用保守的完整新增量预检，可能需要额外剩余空间；课程容量单独计算。

成员表的“重置密码”只对本空间普通成员生效，需输入两次新密码；重置后原登录会话失效。全局账号、其他空间账号和管理员账号不在此入口的重置范围内。页面切换账号时清除旧成员、申请、权限和密码草稿。

## 共享课程

`/courses` 是跨空间共享课程；`/learning` 仍是个人学习资料索引。

1. 空间管理员创建课程并上传资料，在“邀请成员”生成邀请码或链接，可设置长期有效、自定义到期时间和邀请人数上限，之后可主动停用。支持创建多个相互独立的邀请码，详见[共享课程与成员邀请说明](共享课程与成员邀请说明-20261025.md)。
2. 普通成员、其他空间的管理员都可凭加入码参加，原工作空间归属不变。
3. 加入后可读取该课程的共享资料，不能访问创建者的私人云盘。
4. 需要上传时先申请一次上传权限，创建者批准后可持续上传。另一位空间管理员作为课程成员时同样需要批准，不能自行授权。
5. 创建者可拒绝、撤销上传权限、移除成员、停用课程及更新加入码。每次上传、下载重新检查当前权限，退出课程后不再授权后续请求。

课程文件使用独立、不可猜测的对象路径，按课程鉴权下载。默认每文件最多 50 MB、每课程上限 1 GB、每创建者已用总量 5 GB、服务器课程已用总量 20 GB，最多四个同时上传。容量在数据库事务中预留，失败清理后才释放；未完成记录可由创建者查看和清理。

配置项：

| 属性 | 默认值 | 用途 |
| --- | --- | --- |
| `tongligong-student-cloud.courses.storage-root` | `./data/course-materials` | 课程私有文件目录；也可设置 `STUDENT_CLOUD_COURSE_STORAGE_ROOT` |
| `tongligong-student-cloud.courses.max-course-bytes` | `1073741824` | 每课程可设容量的服务器上限 |
| `tongligong-student-cloud.courses.max-owner-bytes` | `5368709120` | 每位创建者课程已用总量上限 |
| `tongligong-student-cloud.courses.max-total-bytes` | `21474836480` | 全站课程已用总量上限 |
| `tongligong-student-cloud.courses.minimum-free-bytes` | `268435456` | 上传后保留磁盘空间的检查阈值 |

课程目录需要持久化，并且不能位于任何 LOCAL 云盘根目录内，也不能包含 LOCAL 根目录。V4 本地部署配置已准备 `/data/course-materials`，尚未更新服务器。共享课程上传文件目前不自动建立个人学习索引；自动解析、增量检索属于后续扩展。

## AI 反馈与知识改进

首次“没有解决”和一次网络失败不自动强推人工。用户明确说“转人工”时仍能打开确认入口；确认后才创建人工会话。点击未解决独立保存本轮问答，不自动共享其他历史、附件或长期记忆。

全局管理员进入 `/admin/ai-feedback`：查看反馈 → 保存人工核对的正确答案并标为已整理 → 可选 AI 辅助润色 → 预览和编辑 → 保存采用的答案 → 明确确认发布。发布后真正参与 RAG 检索；错误原回答不会自动作为知识。

普通反馈默认本空间，通用说明发布到全站需额外确认；来自课程的反馈只能发布回原课程。保留来源、不可变版本历史和撤回能力；退出课程、课程停用、账号停用后重新判断检索可见范围。

批处理方法见 [知识库反馈整理与发布](知识库反馈整理与发布.md)，脚本为 `scripts/curate-knowledge.py`。脚本先导出待审核文件；AI 候选不会覆盖人工答案，发布需要明确确认，不自动启动模型微调。单元测试模拟模型服务，未对真实 API 计费调用或微调作通过承诺。

## 邮件及本轮验证边界

邮箱／账号密码登录、验证码注册与找回密码使用隔离 SMTP 收件器验证。真实 QQ 收信在先前配置时确认过，但本轮没有发送真实验证码；服务器 V4 的邮件仍关闭。恢复部署后再通过隐藏输入配置 SMTP 并进行实际收信验收。

本轮前端以实际 Vue 组件／交互的 JSDOM 测试、类型检查与 ESLint 验证；不把它描述为已经完成所有分辨率、所有浏览器的人工视觉验收。第三方存储写入探针使用模拟提供方和临时目录测试，生产连接还需使用实际存储账号运行验证。
