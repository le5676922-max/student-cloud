# 知识库与 Agent 升级实施记录

本轮在文件业务验收后实施，保留原有界面主题和小芽形象。平台、内容、智能三个业务服务与 Gateway 保持不变，没有更换旧网站的线上环境。

## 1. 项目知识库

新增版本为 `2026-10-26-independent-v1` 的36条内置说明，包含稳定ID、适用角色、关键词、正文和核对源码。覆盖账号、角色、空间、额度和个人目录、续传、回收站、分享、个人学习资料、共享课程、课程上传审批、Agent预览与任务、长期记忆、反馈、知识审核和常见故障。

调用方先从平台服务取得新鲜身份，再按角色筛选帮助。内置说明不读取用户文件，不存密码、Token或私有反馈。没有模型配置时可直接显示真实项目帮助，并明确标注来源，不伪装成模型回答。

`ProjectKnowledgeService` 将项目说明返回到 `knowledge[]`。人工审核知识也在此展示；界面来源为“项目使用说明”或“人工审核知识”，不把内部源码路径作为普通用户的操作说明。

## 2. 中文检索与课程片段

审核知识新增有界词法排序：中文词段/双字片段、英文词边界、常见疑问词过滤、标题权重与稳定排序。一次最多64个不同检索词；仍只从最近500个符合全站/空间/显式课程范围的活动候选中筛选。撤回、被新版本取代或其他空间的知识不参与召回。

个人资料检索同时考虑文件名、标签、第一段标题和正文覆盖度。先在最多200份本人索引中排序，再在新鲜读取预算内核验源文件；每份最多10MiB、每次读取预算50MiB，最多32个检索词。使用重叠窗口选出约500字符的相关片段，避免只返回开头或按最新文件排序。

对话和资料检索统一允许2000字符的提问，修复“对话可以提交但检索拒绝”的不一致。长问题仍受词数和来源预算限制，不意味着无界全文分析。

读取片段仍检查个人课程归属、存储授权与源摘要。即使文件大小和时间未变，内容改变也会被摘要检验排除。索引在读取期间被删除或关联到另一文件时，不返回旧片段。

资料引用保留 `reference`、文件名、片段、`materialId`、`courseId`、`storageKey`、虚拟路径和摘录，支持返回所属课程。界面展示跳过和截断提醒，不把本轮片段称作已阅读全部资料。

## 3. 未解决问题怎样进入知识库

流程为：成员点击“没有解决” → 后端匹配本轮真实问答并记录 → 全局管理员核对与修订 → 可选AI润色 → 人工采用并保存 → 标记已解决 → 确认范围并发布 → 后续检索使用当前版本。

本轮补齐了关键契约：润色接收管理员实际提交的 `administratorAnswer` 和 `expectedUpdatedAt`，不再悄悄使用原来的错误模型答案。空白修订被拒绝，旧时间被拒绝；模型调用后再次检查管理员身份和反馈版本。

润色只是草稿，不自动改库或发布。管理员在等待期间改动未保存的正文，会取消该轮润色；已有草稿也会失效，避免覆盖新的人工编辑。该行为不因每次打字重新读取知识状态。

正式发布仍需已保存的正确答案、反馈版本、更新时间和知识版本全部匹配。课程知识只能留在原课程；含个人资料、附件或私有会话上下文的反馈禁止直接共享发布。发布历史和撤回保留，不自动“训练模型”。

## 4. Agent 行为

`AgentIntentRouter` 集中识别明确的用户指令：整理文件、按日期重命名、导入个人课程资料、检查重复文件、上传指引和删除指引。它只读取本轮用户指令，不读取检索材料来决定操作。

- 询问“怎么整理”只回答方法，不生成操作计划。
- 缺少存储源、目录或个人课程时先明确询问需要补什么。
- 写操作调用现有内容服务生成预览，核对后再由用户确认；不会把回答文字当执行成功。
- 检查重复只进行有界内容校验，报告检查和跳过数量，不删除文件。
- 上传使用现有文件选择/拖入及目标确认流程；临时分析附件不会默默保存为云盘文件。
- 明确的否定、禁止、取消或“不移动”等限制不会被当作批量整理指令。

确认任务时新增调用方事务内的任务创建API。计划状态、任务和Outbox事件共同提交：计划关联失败时三者一起回滚，修复“确认失败但孤立任务仍可能执行”的窗口。普通独立任务创建继续使用独立事务。测试注入了计划更新失败并核对无任务/无事件残留。

## 5. 回答格式与来源复核

简洁模式明确要求先回答问题，使用少量短段落或必要步骤；详细模式解释前提、理由、步骤、例子和限制。两种模式有不同指令，不能仅用输出长度代表风格。

前端安全渲染段落、列表、引用和代码围栏，使用正常Markdown空白规则与主题颜色。流式过程先显示完整行，最终保留完整正文；错误提示单独展示，避免被未闭合代码块吞掉。

模型返回的资源标签在额外DOM解析之前过滤，不能用远程图片隐式加载资源；普通安全链接仍可点击。知识、附件、长期记忆和历史均被声明为数据，不将其当作执行指令。没有真实工具结果时不得声称已上传、移动、删除或训练。

模型调用后重新核验账号角色/空间、用到的审核知识版本、课程片段和已用记忆；权限被撤销、来源变化或记忆关闭时拒绝返回旧上下文。私有来源标记随服务器保存的完整回答保留，反馈不能靠客户端改写解除限制。
