# 文件夹双击异常修复记录

## 问题与原因

在双击打开模式下，首次单击普通文件夹会选中该行。原有选择操作栏以新一行插入文件列表上方，将目标向下推，第二次鼠标点击无法落到同一元素，因而不能稳定触发双击。真实浏览器测得文件名按钮由 top 513.5 移到 552.5，相差 39px。Enter 直接打开目录，云盘入口又不参与普通文件选择，因此它们可以正常打开。

## 修复

- 在文件页原有工具栏区域中显示选择操作，不在文件列表上方新增一行。
- 原浏览控件保留几何尺寸，选中期间隐藏并设置 inert / aria-hidden，避免隐藏控件仍可聚焦或被辅助技术读出。
- 选择栏在同一区域内定位，窄屏下操作按钮可横向滚动；不覆盖文件行。
- 保留原单击选择、双击打开、键盘打开和后端权限，不增加点击延时。

运行文件：`frontend/src/pages/file.vue`、`frontend/src/components/file/FileSelectionToolbar.vue`。新增回归在 `frontend/tests/drive-page-runtime.test.mjs`。

- 选择前后列表内容位置不变（contentTop 526.5 → 526.5）；卡片 offsetTop 380 → 380。卡片已有 hover 的 -3px transform 是视觉动效，不是新增文档流位移。
