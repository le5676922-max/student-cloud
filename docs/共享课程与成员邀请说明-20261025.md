# 共享课程与成员邀请

## 入口与基本流程

本地入口为 `http://127.0.0.1:5173/courses`。空间管理员可从工作空间管理的“共享课程 / 邀请成员”进入；普通成员和空间管理员也可从云盘账户菜单进入“共享课程 / 邀请加入”。个人资料库 `/learning` 保留，只归本人使用。

1. 普通管理员（空间管理员）创建共享课程，填写名称、介绍和课程容量。
2. 在课程中上传资料。资料保存在独立课程区，不开放创建者的个人云盘。
3. 点击“邀请成员”，选择邀请码的有效期和人数上限，再生成邀请码或邀请链接。
4. 将邀请码或链接通过自己选择的方式发给受邀者。网站不会自动替你发邮件或消息。
5. 受邀者登录后预览课程，明确确认加入；打开链接不会自动加入。
6. 加入后可查看、下载该课程的共享资料。普通成员和其他空间管理员均可加入，包括其他工作空间的账号，原空间归属不变。

## 邀请码规则

| 设置 | 行为 |
| --- | --- |
| 长期有效 | 没有时间上的到期日，创建者仍可主动停用 |
| 指定有效期 | 可选择常用期限或自定义未来到期时间 |
| 不限邀请人数 | 不设置该码的人数上限；仍受课程总成员数等系统限制 |
| 限制邀请人数 | 可设 1–500 人，以通过这个码实际加入的不同账号计数 |
| 多次创建 | 可持续创建多个邀请码，每个码的有效期、人数和停用状态独立 |
| 同一码多人加入 | 不会使用一次就自动失效；到期、停用或达到人数上限后不能再邀请新账号 |
| 重复点击加入 | 已加入的人不会重复占名额；同一码已计数的人退出后重入不再重复计数 |
| 达到上限 | 新账号不能再使用这个码；已加入者仍保留课程访问 |
| 主动停用 | 只停止该邀请码的后续加入，不会自动移除已有成员，也不影响其他邀请码 |

“已邀请人数”是该邀请码累计成功邀请的不同账号数，不等于课程当前人数。成员退出不会把已用名额退回；创建者可另建邀请码。被创建者移出课程的账号不能通过换一个邀请码绕过移出决定。

邀请码只在生成时显示原文，请及时复制并妥善分享；服务端仅存哈希。关闭后刷新页面仍可管理已生成邀请的状态、人数和期限，但不能重新取回原码，可另行创建新码，原码按原设置继续有效。邀请记录支持分页查看和停用。

历史课程的旧加入码继续兼容。高级操作中的停用旧版邀请码用于让旧码失效；新邀请应通过“邀请成员”窗口创建，以设置期限和人数。

## 上传审批与隐私

- 加入课程默认获得共享资料查看、下载权限。
- 需要上传时，成员点击“申请上传权限”。只有课程创建者能批准；批准后可持续上传，直到创建者撤销或成员退出／被移出。
- 其他普通管理员加入别人创建的课程时也属于课程成员，需要申请上传，不能自行审批。
- 邀请链接预览只返回课程名称、介绍、是否已加入等必要信息，不返回成员邮箱、账号资料或云盘连接配置。
- 课程成员不能因此查看他人的私人云盘、个人索引或长期记忆。成员列表与邀请管理只供创建者使用。
- 课程停用、创建者停用、上传权限撤销及成员移出会在后续请求重新检查，不依赖页面上缓存的旧权限。

邀请人数限制不能替代课程容量限制。当前课程最多加入 500 位成员，每个账号最多加入 50 门共享课程；上传的文件大小与课程容量继续受服务端校验。

## 服务接口

所有接口要求登录；创建邀请、查看邀请列表和停用邀请还要求当前账号为该课程创建者。

| 方法与路径 | 用途 |
| --- | --- |
| `POST /api/courses` | 空间管理员创建共享课程 |
| `POST /api/courses/{id}/invitations` | 创建邀请码；`expiresAt=null` 为长期有效，`maxMembers=null` 为不限人数 |
| `GET /api/courses/{id}/invitations?offset=0&limit=20` | 分页查看邀请码状态，不返回原码或哈希 |
| `DELETE /api/courses/{id}/invitations/{invitationId}` | 停用指定邀请码 |
| `POST /api/courses/invitation-preview` | 携 `{code}` 查看受邀课程预览，不创建成员关系 |
| `POST /api/courses/join` | 携 `{code}` 明确加入课程 |

`expiresAt` 使用毫秒时间戳，必须是未来时间；`maxMembers` 为 1–500 的整数。创建新码不使其他邀请码失效。后端在同一课程行锁及数据库事务内校验邀请、写入成员与记录独立用户人数，以防并发抢占最后名额时超限。
