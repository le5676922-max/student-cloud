# 业务优化实现与回归说明

> 本文记录本日较早的一批优化，不代表后续功能状态。随后新增邮箱重置、路径同步、共享限流、S3 快分页及可选 OCR/语义索引，见 [业务缺口修复与外部嵌入配置](业务缺口修复与外部嵌入配置-20261010.md)。

日期：2026-10-10。开发范围：本仓库的 [前端](../frontend/) 与 [后端](../backend/)。

本轮在现有项目中实现优化，没有提交或推送 Git，没有替换小芽外观，也没有修改真实业务数据库、真实云文件或真实云端跨域规则。

## 1. 上传目标与取消

- 每个任务创建时固定存储源、目标目录、上传方式、账号/空间及目录密码上下文。排队继续和失败重试沿用该目标，不随当前网页目录改变。
- 从创建目录、申请上传地址开始就支持取消；取消后，迟到的签名、进度及成功回调不再启动传输或显示成功。
- 同名文件按任务编号分别删除，不再误取消另一个同名任务。
- 切换账号/空间或退出登录会取消并清空旧任务。刷新同一账号的普通展示信息不会误取消上传。
- 保留 OneDrive 分片上传；取消标记覆盖后续分片。拖拽文件夹读取全部目录页，文件夹选择器也会在需要时创建层级目录。
- 切换存储源/目录时同步清除旧操作权限与用户根目录；新目录授权完成前不能创建新的上传任务。

这不是通用断点续传。取消浏览器请求不保证云服务撤销已经接收的文件或分片；结果不确定时需要核实目标目录。文件仍必须由用户选择，网页不会读取电脑上的任意文件。

## 2. 存储源保存与独立连接测试

入口：全局管理员后台 → 存储源连接 → 添加/编辑存储源。

| 操作 | 实际行为 |
| --- | --- |
| 智能识别、检查填写 | 前端本地格式检查，不连接服务、不保存 |
| 只读测试连接 | 独立后端接口验证支持的连接，不保存、不写文件、不写跨域规则 |
| 保存设置 | 保存数据库配置，准备并验证新连接，提交成功后替换旧连接 |
| 应用已保存的跨域规则 | 仅在已有源上明确确认后，使用后台已保存的配置写入远端桶 |

新连接准备失败或数据库事务回滚时，原连接仍可用，准备中的连接会释放。提交后更新 ID/key 注册关系，再清理旧连接。行政配置变更有并发保护；冲突时明确拒绝，不同时覆盖同一份连接状态。

独立只读测试目前支持：

- 本地绝对目录：检查存在、目录类型和可读属性，不列文件、不创建目录，不支持 UNC/网络共享预检。
- S3、OSS、MinIO、华为、腾讯、七牛兼容类型：读取目标前缀最多一项元数据；检查公网地址，固定经过验证的 DNS 地址，有限并发与超时。

FTP/SFTP/WebDAV 等协议暂不支持独立预检；私网端点也不能通过该辅助接口探测。只读成功不代表上传、删除、移动权限均已验证。普通保存流程仍保留原协议的连接验证。

所有 S3 类正常初始化、保存、重启均不再自动调用远端 CORS 写接口。私网存储若需 CORS，请在提供方控制台或受控部署环境配置，不绕过辅助接口的出站限制。应用 CORS 的网络错误可能意味着结果未知，应先读取远端规则核实。

## 3. 页面启动与大目录

- 配置和应用模块加载期间显示站点加载提示及重新加载入口，不再一直空白。
- 小芽组件改为异步加载，仅在已登录的业务页挂载；登录、初始化、SSO 页不加载该组件和形象资源。
- S3 兼容目录按一次分页响应遍历，同时处理文件与文件夹，避免分别遍历两次远端列表。
- 分页请求只为当前页可读取的文件生成下载链接；不再给目录里的每个对象生成链接后才截取一页。
- 增加进程内 5 秒元数据快照，最多 32 个目录、50,000 项及 5,000,000 个名称/路径字符；单目录超过 20,000 项不保留快照。
- 快照按连接实例、账号、授权根目录和目录隔离，不缓存下载签名、密码、凭据或授权。每次请求仍检查当前账号、源状态、授权及原有目录密码/隐藏规则；授权根目录或规则授权不一致时拒绝返回。
- 文件变动使快照失效；显式刷新、导航和上传完成后的目录重新加载绕过快照。旧的在途请求不能在失效后重新填入过期快照。

这轮主要优化 S3 类目录。第一页仍需枚举完整目录以保持全局排序和搜索；不是所有协议的原生分页，也不是跨实例强一致目录缓存。外部客户端或其他实例修改文件时，短时快照可能最多保留 5 秒，手动刷新可立即重新读取。

生产构建的入口 JS 约 462 kB（未压缩传输前的构建文件），小芽独立成约 46 kB 模块。该数字不是实际网络响应时间或并发性能承诺；PDF、视频、3D 等预览块仍较大。

## 4. Redis 元数据读路径

现有 Redis 可选配置继续保留，不强制开启、不改变用户 Redis 数据库配置。

- 健康命中不再通过全局同步方法逐个排队，允许并发读取。
- 用一次 MGET 同时读取快照与版本标记，常规命中由三轮 Redis 读取减少为两轮。
- 缓存未命中时仅合并数据库加载；等待数据库连接时不持有生命周期锁，避免提交后失效与数据库连接池相互等待。
- 变更仍切换版本；旧数据库读取不能填入新版本快照。Redis 故障时回源数据库，不自动恢复可能过期的旧快照。

账号、权限及连接凭据仍不进入这一显示元数据缓存。

## 5. RAG 资料覆盖

入口：学习资料库 → 添加资料或重新索引。

- 持久知识库提取独立于聊天附件，最多 240,000 个 UTF-16 字符、PDF 最多处理 300 页，文件仍最多 5 MB。
- DOCX 增加解压内容和结构安全上限，避免小压缩包无限膨胀。
- 保存索引版本、实际文字长度、PDF 处理/总页数、是否达到上限及索引说明。
- 页面显示完整可提取文字、部分索引或旧版覆盖未知；旧资料需主动重新索引才能得到扩大后的内容，不会伪造覆盖范围。
- 现有有重叠分段的关键词检索可找到长文后部；返回片段前仍复核当前权限和实际文件指纹，不复用跨请求授权。

聊天附件的原有 12,000 字符/30 页限制没有扩大。扫描图片没有新增 OCR；PDF 页数是已处理页数，达到文字上限时末页可能只处理了一部分。本轮没有接入向量数据库，也没有将关键词检索宣称为向量检索。

## 6. 定时 Agent 预览恢复

入口：自动化工作台 → 定时规则。

- 临时连接、超时或瞬时数据库故障可在 1 分钟、5 分钟后有限重试生成预览；最多两次自动补偿，不无限重试。
- 规则、权限错误及未知结果不盲目自动重试，显示检查提示并提供手动生成入口。
- 用数据库 CAS 认领、持久认领期限和每次触发固定任务 ID，防止多个实例或重复请求创建同一触发的多个预览。
- 已保存但规则状态写回不确定时，可以复用同一次触发的任务；手动操作不会直接重放文件写入。
- 普通重试不改变下一次每周执行时间；展示等待、生成中、等待重试、失败、结果不确定或预览已生成状态。

**定时任务仍只生成预览，文件移动、重命名和资料索引需要用户确认。** 没有新增无人值守执行、任意系统命令或自动撤销已经完成的文件操作。

预览 CAS 防重不等于整个应用已支持多实例部署；执行队列、启动恢复、连接上下文及其他进程内缓存的原有限制仍然存在，当前不要直接用多个后端副本共享业务库运行文件自动化。

## 7. 数据库升级与部署

新增 MySQL/SQLite 两套 Flyway 迁移：

- V69：扩大资料文字字段，增加覆盖范围信息。
- V70：增加定时预览认领、有限重试和关联任务字段。

生产浏览器模拟脚本与结果报告仅保留在本地忽略目录，不是生产服务。本地验证原始日志未随源码发布，本文保留测试日期、范围、结果和限制，不提供不可访问的本机链接。
