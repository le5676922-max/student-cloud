# 学生云盘

学生云盘是一个面向学生个人学习场景的文件管理项目，支持统一管理本地存储、对象存储、WebDAV、FTP、SFTP 等多种存储源。

## 主要功能

- 文件浏览、上传、下载、移动和在线预览
- 多存储源统一管理
- 用户登录、权限控制和分享链接
- 图片、音视频、文本、PDF 与 Office 文件预览
- 响应式页面，支持电脑和手机访问

## 本地开发

## 技术栈

Vue 3、Vite、Element Plus、Tailwind CSS、Spring Boot、MyBatis-Plus、MySQL。
