# 独立云盘应用服务

本模块将独立账号、JDBC 授权与 `cloud-drive` 文件内核接起来，不依赖旧后端驱动、表、DTO、权限责任链或静态会话。数据库脚本 `db/independent-drives-schema.sql` 必须在独立账号表之后执行；上层统一安排迁移版本，不能导入旧云盘表。

## 当前可用范围

- 全局 `ADMIN` 创建 LOCAL 连接，物理目录须已存在并位于配置的 `managedRoot` 内；根或中间路径存在符号链接即拒绝。未配置受控根目录时连接能力返回明确不可用。
- 连接可由全局管理员绑定现有工作空间，但不会自动给成员授权；列表视图不返回物理路径。
- 每次文件访问重新读取账号、空间启用状态、连接及显式授权；客户端提交的角色或工作空间不作为依据。
- 普通管理员及成员必须属于连接的同一空间并拥有有效授权。成员的根必须精确等于 `/members/u{账号数据库ID}`，不会接受空间根或他人个人目录。
- `list`、`read`、`mkdir`、`upload`、`copy`、`move`、`rename`、`delete` 为当前完整权限白名单；数据库逗号分隔的授权出现未知值，整项拒绝。
- 所有真实文件操作均经过 `LocalFileStore`；上传默认不覆盖，先暂存并验证实际长度，发布前再次核验授权与版本。单次传输上限 50 MiB，递归操作最多 10,000 节点，错误转换为不泄漏主机路径的 `ApplicationFault`。
- `WorkspaceCloudService` 提供成员云盘申请、本空间普通管理员审批及授权编辑。授权只授予该管理员已拥有操作的子集，成员目录固定为 `/members/u{ID}`，不暴露他人个人目录。
- 普通管理员申请本地云盘时不填写任意服务器路径；全局管理员批准后，服务在受控根下分配唯一目录、创建连接及管理员自己的 `/admins/u{ID}` 授权。失败只尝试清理本次分配的空目录。

## 容量与写入预算

`quota_bytes` 已进入 LOCAL 写入判断：上传及复制增加容量前，在连接行锁和成员授权行锁保护下核算实际个人目录大小，拒绝超额；同连接下的全部变更（包括全局管理员变更）使用同一数据库行锁串行化。删除、重命名和同一可见根内移动不会新增计量用量，超额状态仍允许删除。空配额表示明确未设限，不能在界面显示成已限制容量。

容量核算拒绝符号链接、特殊文件、遍历失败、溢出及超预算扫描；扫描最多 10,000 个节点、128 层及 15 秒，不把无法确定的使用量当成零。它是有界真实目录核算，**不是常数复杂度用量账本或配额预留系统**。大目录可能被预算拒绝，后续需要可恢复的用量账本与核对流程。

上传接收流先写入系统私有临时文件，暂存目录不能位于可浏览根内，每个应用实例最多两个暂存上传。网络读取阶段不持 SQL 事务；长度匹配后才进入短时授权复核和文件发布流程，结束时清理本次临时文件。实际磁盘复制、递归核算及变更仍可能在数据库行锁内执行，事务超时配置为 30 秒；这是一致性优先的当前实现，不能宣称大目录并发性能已优化完成。

数据库行锁协调的是共同使用同一库、同一连接记录和同一实际文件树的应用实例。它不把两台服务器的独立本地目录变成共享存储，也不约束直接改动宿主机文件的外部进程。SQL 回滚不撤销已经完成的文件系统副作用；跨介质恢复和失败后的自动校准仍未完成。

## 公开接口

`MountService(JdbcTemplate, PlatformTransactionManager, Clock, Path managedRoot)` 提供：

- `listMounts(actor)` 与 `createLocal(actor, name, key, root[, workspaceId])`
- `list`、`stat`、`mkdir`、`upload`、`readWithMetadata`
- `copy`、`move`、`rename`、`delete`

文件路径使用 `DrivePath`，元数据使用 `FileRecord`；`ReadHandle` 含元数据及输入流，实现 `AutoCloseable`，HTTP 适配器必须在正常完成、客户端断开和异常时关闭它。上层需要把内核权限映射到前端按钮名称，不能直接继承旧权限表或将未知权限当作许可。

`WorkspaceCloudService` 另提供 `requestCloud`、`listMyRequests`、`pendingForWorkspaceAdmin`、`approveCloud`、`rejectCloud`、`updateMemberGrant`，以及 `requestLocal`、`listMyLocalRequests`、`pendingLocalForGlobalAdmin`、`approveLocal`、`rejectLocal`。审批与授权接口必须接收服务端认证的身份，不能从浏览器自报角色创建 `Actor`。

## 尚未完成与验证边界

目前只实现 LOCAL；S3 或其他 engine 明确返回 501，不调用旧驱动或退回本地目录。成员采用固定隔离根，尚未开放任意文件夹范围授权。连接写入探针、断点续传、链接分享和完整旧存储表单适配仍待完成。

上传完成后的授权复核缩小撤销窗口，已建立读取流不逐字节重新鉴权。底层不支持不可信宿主机进程同时改动受控目录，部署需以服务账号与挂载边界隔离。

已有测试源码覆盖隔离 H2/JDBC 和临时目录 CRUD、角色伪造、跨空间、个人目录、即时撤销、上传结束撤销、容量增长拒绝/删除释放、未知权限、配置禁用、受控根逃逸和错误脱敏。测试本轮未执行，审批服务的测试覆盖尚待补齐。根工程负责必要编译；不据此宣称真实 MySQL、多进程或生产文件系统验收通过。
