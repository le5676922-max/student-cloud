# 独立课程协作模块

自有实现只依赖独立账号公开身份、通用错误及 JDBC 事务，不引用旧业务代码、表或迁移。入口模块在账号 schema 之后应用 `db/independent-courses-schema.sql`，显式装配 `SharedCourseService(JdbcTemplate, PlatformTransactionManager, Clock)`。

## 已实现的真实业务

- 普通管理员创建和管理自己的共享课程；普通成员及其他普通管理员可跨空间加入，原空间和私人云盘授权不会被修改。
- 创建、读取、修改、暂停及删除空课程。非空课程须由资料服务协调清理后删除，课程服务不会假装删除了真实文件。
- 多个独立邀请，可长期有效、未来到期、限 1–500 个不同账号、随时撤销。创建每课程每分钟最多 5 次，正常长期创建不受“一次性创建”限制。
- 16 字节安全随机邀请码，32 位十六进制；数据库只保存 SHA-256，原码仅创建时返回。列表和预览不泄露哈希、邮箱、用户名及其他空间信息。
- 每邀请码记录历史不同账号占位。主动退出不退还名额；同人重入不重复扣名额，上传审批清空。创建者移出后，不能通过另一邀请码绕过。
- 课程行锁串行化加入、邀请变更和成员审批，竞争最后名额只有一个成功。
- 成员默认只读；主动申请上传，创建者批准后持续有效，也可拒绝/撤销。创建者权限和账号、空间启用状态均重新从数据库核验。
- 成员上限 500，单账号最多加入 200 门课程，创建者最多 50 门；课程配置容量 1 MiB–1 GiB，具体文件用量由资料服务记账。

## 私有资料存储

`CourseMaterialService` 已提供真实上传、下载、删除及不完整记录查询，采用独立 `LocalFileStore`。入口须在课程 schema 后应用 `db/independent-course-materials-schema.sql`，并明确配置既有绝对私有目录；未配置时返回 503。该目录必须由入口验证与所有可浏览云盘根互不重叠，不得将课程目录映射到云盘根。

上传限 50 MiB；每创建者所有课程合计 2 GiB、全站合计 6 GiB，计算包含待上传、已就绪和待删除记录。全局预算行与课程行只在短 SQL 事务中锁定，读上传流与实际文件操作不持数据库锁，文件发布前再次检查上传授权。每课程最多 1000 个活动资料记录，全站最多 100000 个。显示原名不参与物理路径，私有对象使用随机名。

数据库与文件系统不是一个原子事务。状态为 `PENDING → READY → DELETE_PENDING → DELETED`；失败清理只处理本次拥有的文件，清理失败保留占用和记录，可由创建者重试删除 `DELETE_PENDING`。正在上传的 `PENDING` 不允许提前删除释放容量。**进程崩溃遗留的 PENDING 暂无自动恢复程序，必须核验上传已结束后再进行受控修复；不能直接改成成功、删除记录或释放容量。**删除非空课程前须通过资料服务完成文件清理。

下载仅允许有权课程成员读取 READY 对象，打开文件后再次鉴权；元数据不包含邮箱、登录名、上传者身份或物理路径。返回的 `MaterialDownload` 必须由 HTTP 适配器在流结束、异常及取消时关闭。

## 尚未实现

当前没有旧版课程共用邀请码；应使用新独立邀请接口。本模块不自动导入旧课程或用户数据，也不重建现有业务库。

## 验证范围

测试源码使用独立 H2 MySQL 模式数据库，覆盖跨空间共享、角色伪造拒绝、邀请秘密、审批、占位、移出保护、最后名额并发、过期撤销、课程 CRUD、启用状态变化，以及真实私有文件上传/下载/删除、配额、异常清理、读流不持 SQL 事务与权限中途撤销。真实 MySQL与HTTP联调由入口工程统一验证，本模块不声称已上线。
