# cloud-drive：独立本地文件内核

本模块只依赖 JDK 21；测试使用 JUnit 5。不依赖旧存储驱动、旧 DTO、静态存储注册表、数据库、登录会话或 Spring。调用方必须先完成账号、空间、目录和配额授权，再选择物理根目录并执行内核操作。

## 公共 API

```java
DrivePath.of("/课程/讲义.pdf");
new LocalFileStore(existingRoot, 10_000, 50L * 1024 * 1024);
```

- `DrivePath`：平台无关的虚拟路径，支持 `child`、`parent`、`name`、`value`；不接受宿主机磁盘路径。
- `FileRecord`：虚拟路径、文件名、目录标志、大小和修改时间，不携带物理路径或授权下载地址。
- `list` / `stat`：列出直属子项或查看元数据；缺失文件 `stat` 返回空。
- `createDirectory`：创建一个目录，父目录须存在；已有真实同名目录可重复调用。
- `write(path, input, expectedBytes, replace)`：声明大小必须准确；默认拒绝同名，覆盖须显式开启。调用方负责关闭输入流。
- `read`：返回须由调用方关闭的流，读取总字节仍受预算约束。
- `copy` / `move`：默认拒绝任何同名目标；目录不能复制或移动到自身及后代。
- `delete`：先遍历完整有界子树，检查通过才开始删除；不能操作根目录。

文件系统操作抛出 `IOException`；虚拟路径语法或构造预算错误抛出 `IllegalArgumentException`。HTTP 层应映射为业务错误，不能直接将底层文件系统异常中的主机路径返回给用户。

## 安全与资源约束

1. 根目录必须已存在，且本身及现有祖先不能是符号链接或特殊重定向条目。后续操作会重新检查根目录和路径各级，不跟随符号链接。
2. 禁止 `..`、`.`、反斜线、冒号（含 Windows ADS）、控制字符、Windows 保留名、末尾点/空格与过长路径。百分号不做 URL 解码，HTTP 层需按其约定完成一次解码后传入。
3. `.studentcloud-` 是内核保留的临时文件前缀，不能通过虚拟路径访问；列表不展示这些临时项。
4. 写入先进入同目录随机临时文件，大小不符、流中断或超限时清理临时文件，原目标保持不变。非覆盖发布使用硬链接原子占位，文件系统不支持时拒绝操作；显式替换要求支持原子移动，失败不退回非原子覆盖。
5. `maxEntries` 限制列表子项数及递归操作节点数（递归包含源根节点），`maxTransferBytes` 限制单次读写与递归操作总文件大小；最大递归深度 128。超限报错，不将截断结果冒充完整列表。
6. 目录复制先建立随机私有暂存树，完成后改名发布；清理只针对该次生成的暂存树。递归删除在预检后仍可能因磁盘错误或并发变化而部分完成，不提供事务回滚。

普通 JDK NIO 检查不能消除恶意宿主机管理员在路径检查与系统调用之间替换目录的竞争，也不能把硬链接已有的宿主机数据当作独立安全边界。部署者须让物理根目录及其祖先只由受信任服务账号管理，并用独立挂载/容器权限隔离；不支持不可信本地进程同时修改该目录。目录移动和暂存树发布受同一实例的串行写保护，不承诺跨进程恶意竞态下的事务语义。

本模块实现的是本地文件 I/O，并不表示整个历史项目已经独立；S3/其他协议、授权应用层、配置持久化和接口兼容需要由独立工程继续实现。

## 测试范围

源码包含路径规范化与拒绝规则、UTF-8/空文件、冲突、精确长度、传输中断、临时文件清理、覆盖完整性、预算、递归复制/移动/删除、链接拒绝及两个实例竞争同名发布等测试。符号链接测试在缺少创建权限时明确跳过；不能把跳过当作通过。本轮开发未自行运行 Maven，由上层统一编译与验证。
