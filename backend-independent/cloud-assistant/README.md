# 独立助手记忆与知识整理模块

本模块使用独立账号契约、公共错误及 Spring JDBC/事务，装配到 `cloud-intelligence-service`。账号与空间状态通过 `AccountDirectory` 端口交由账号服务复核，助手自身不查询、锁定或复制账号数据库表。表结构资源为 `db/independent-assistant-schema.sql`，只应用到智能服务自己的数据库；不读取旧聊天表或旧秘密配置。

## 账号长期记忆

`MemoryService` 提供列表、设置、创建、修改、删除、清空、启用/停用及关键词召回。每账号最多 50 条，每条最多 500 字符；内容只对本人开放。编辑与单条删除使用版本条件，避免较旧页面覆盖新数据。创建、修改时复查启用状态和重复内容；停用后召回为空，但不自动抹除本人保存的记录。

记忆是持久化业务记录，并非自动收集全部聊天。当前召回是在本账号最多 50 条记忆中做有界关键词匹配，没有向量召回或模型生成摘要。已接入 `/api/ai/memories` HTTP 适配；聊天模型还未接线，不应描述成模型已经自动使用这些记忆。

## 未解决反馈

`AnswerFeedbackService` 仅接收用户主动选定的一组问题、回答、客户端消息标识及可选课程上下文。同一账号同一消息标识、相同内容与相同课程的重复提交返回原反馈，内容或课程不一致返回 409；不能借重试把课程问题变为普通空间问题。指定课程时通过自有 `CourseKnowledgeAccess` 端口核验当前课程读取资格，服务装配使用内容服务内部授权 HTTP 接口，助手不依赖课程实现或查询课程表。

全局管理员整理队列、读取详情、填写修正答案及内部备注并修改状态。状态为 `OPEN`、`REVIEWING`、`RESOLVED`、`DISMISSED`，标记已解决必须填写修正答案，更新需要匹配当前版本。通用人工导出排除课程来源，避免省略范围的问答文件混入课程私有知识；暂未实现课程定向导出。

用户只可读取自己的提交；普通管理员不获得本空间成员的私人问题列表。全局管理员收到的是明确提交的反馈，不因此获得其他聊天、记忆、文件或邮箱。HTTP 提交接受可选字符串 `courseId`；本人列表、管理列表及详情保留字符串课程标识，内部备注仅向全局管理员返回。反馈幂等和记忆条数预算使用智能数据库自己的 `sc_assistant_owner_guard`，不再跨服务锁账号行。旧页面已接入分页、备注和版本字段，网关与多进程联调状态以根记录为准。

## 审核后发布知识

`ReviewedKnowledgeService` 从已解决反馈的修正答案生成可检索条目。发布需要匹配反馈版本；浏览器审核入口还比较修正答案、更新时间和当前知识版本。普通来源的 `TENANT` 仅允许原反馈所属空间，`GLOBAL` 需要明确全站发布确认；**课程来源只能发布为 `COURSE` 并绑定原课程，禁止发布为空间、全站或另一课程知识**。没有课程来源的反馈不能指定任意课程发布。表约束保证活动记录的范围与空间/课程字段互斥。

重复发布相同审核版本及内容返回原条目；内容变化生成下一版本并替代旧活动版本。全局管理员可按版本撤回、查看状态及最多 50 个历史版本，检索只使用未撤销、未被替代的最新活动版本。

用户默认检索全站知识及本人空间知识，不查询课程知识。显式传入 `courseId` 后，在查询候选前和返回结果前复核课程成员资格，才允许加入该课程知识；不会遍历或暴露其他课程的标题、内容、命中数。空间变化也要求重新检索。每次只读取最近最多 500 个合格候选并返回最多 20 条命中，不搜索原始私人反馈问题。当前是有界关键词检索，排序与覆盖范围有限，不能声称已完成语义 RAG、嵌入索引、自动训练或无限规模全文检索。

流程为：

```text
用户点击未解决 → 后端保存反馈 → 全局管理员核验并修正
→ 标记已解决 → 明确发布范围与版本 → 知识可检索 → 必要时撤销/更新
```

“未解决”不会自动转人工，也不会自动将私人原文发送给模型。AI 润色、模型回答、资料解析、embedding、Agent 计划确认及执行器仍未接入；持久化任务由 `cloud-tasks` 提供基础状态，不能代替实际执行。

当前文本校验处理长度及控制字符，不自动识别或脱敏正文中的密码、API key 等秘密；发布前仍须人工核对修正答案和范围。权限隔离不能代替内容审查，也不表示任何答案都可公开。

## 实施状态

模块已经历独立单体阶段的编译与隔离基本流程检查；本次微服务拆分之后，最新构建与多进程验证状态以根工程记录为准。新增边界测试故意不创建身份、空间和课程表，以验证助手通过端口完成业务；测试源码是否执行必须单独报告。未调用外部模型，也未切换现有网站。
