# 账号与平台服务

独立 Spring Boot 进程，默认 `127.0.0.1:18101`。只装配账号、工作空间、会话和人工客服，不包含文件、课程、助手知识或任务实现。

## 数据与接口

自有 `student_cloud_platform` 库，现有5份迁移：V1 身份、V2 人工客服、V3 邮箱验证码、V4 空间邀请与加入申请、V5 注册资料。生产账号/空间/会话表只由本服务读取；其它服务通过纯 `cloud-account-api` 契约的 HTTP 客户端访问。

- 公开初始化与账号/邮箱登录，没有默认管理员密码。
- 邮箱验证码注册与找回密码：空间管理员直接创建启用空间，成员凭邀请码直接加入、凭空间名等待本空间管理员审批；公开注册不能创建全局管理员。
- 邀请码可连续创建，支持到期时间、人数上限、长期有效、不限人数与撤销；加入空间不自动授予云盘或课程权限。
- 工作空间管理员和本空间成员管理，密码摘要和会话数据不返回浏览器。
- 成员分页返回昵称及加入状态，批量读取相关资料，避免每名成员分别查询形成 N+1；存储数量通过内容服务读取，依赖故障时明确标记不可用。
- 登录会话注销、密码版本与账号/空间停用复核。
- 找回密码成功后撤销旧会话，保留账号停用和待审核状态，不绕过空间加入审批。
- 人工服务 HTTP 持久化及 WebSocket，客户端 URL 只带一次性票据。
- `/internal/identity/**` 为内部会话、账号和空间状态接口，必须验证独立服务密钥，网关不向公网开放。

`SC_INTERNAL_KEY` 为32–200字符随机值。生产使用与其它服务一致的安全配置，不将其当作用户 Token。共享运行时提供 CORS、客户端预算和错误映射；平台认证使用本地身份服务，避免内部自调用。

## 配置

默认 H2 内存库仅用于本地开发。`mysql` profile 使用 `SC_DB_URL`、`SC_DB_USER`、`SC_DB_PASSWORD`；也可用 `SC_PLATFORM_DB_*` 显式覆盖。库名只接受 `student_cloud_platform` 或其下划线后缀，不能连接旧项目库。

`SC_PLATFORM_PORT` 优先于 `SC_PORT`。来源由 `SC_ALLOWED_ORIGINS` 指定，`readyz` 检查本服务数据库。生产仅通过 VPC 暴露所需内部端口，浏览器统一经过 Gateway。

SMTP 由本服务的 Spring Mail 适配器提供，默认关闭；注册、找回和邮件能力分别通过环境变量控制，未配置时入口如实停用。验证码按用途隔离、只保存摘要并一次性消费，发送具有并发限制与超时。QQ SMTP 私有配置及使用流程见 [配置指南](../deploy/microservices/邮箱注册与QQ-SMTP配置.md)。真实 QQ SMTP 尚未配置或验证，不使用旧项目的邮箱授权码。
